Module 1: Linux Fundamentals

🇬🇧 English Definition

Linux is an open-source Unix-like kernel. A Linux distribution combines the kernel with user-space utilities, libraries, package management, and applications.

🇮🇳 Hinglish Definition

Linux ek open-source, Unix-like kernel hai. Distribution me kernel ke saath utilities, libraries, package manager aur applications milkar complete operating environment banta hai.

Module 5: Permissions, Ownership and ACL

🇬🇧 English Definition

Permissions define owner, group, and other read/write/execute rights (r=4, w=2, x=1). ACLs provide fine-grained access control beyond standard octal permissions.

🇮🇳 Hinglish Definition

Permissions me owner, group aur others ke read/write/execute controls hote hain. ACL specific users ko finer-grained access deta hai.

💻 Permissions & ACL Commands Created by Gagan Sir 
ls -l file
chmod 755 script.sh
chown user:group file
getfacl file
setfacl -m u:alice:r file
chmod 1777 shared_dir
📤 Terminal Output:
-rwxr-xr-x 1 user group 1024 Oct 4 18:00 script.sh // file: file user:alice:r-- mask::r--

Module 15: LVM Storage Management

🇬🇧 English Definition

LVM provides flexible dynamic storage management: Physical Volume (PV) -> Volume Group (VG) -> Logical Volume (LV) -> Filesystem -> Mount Point.

🇮🇳 Hinglish Definition

LVM se storage ko flexible tarike se pool aur resize kar sakte ho. PV physical storage, VG pool aur LV logical storage hota hai.

💻 LVM Volume Creation & Extension Created by Gagan Sir 
sudo pvcreate /dev/sdb
sudo vgcreate vgdata /dev/sdb
sudo lvcreate -L 10G -n lvdata vgdata
sudo lvextend -L +5G /dev/vgdata/lvdata
sudo resize2fs /dev/vgdata/lvdata
📤 Terminal Output:
Physical volume "/dev/sdb" successfully created. Volume group "vgdata" successfully created Logical volume "lvdata" created. Size of logical volume vgdata/lvdata changed from 10.00 GiB to 15.00 GiB.

Module 32: Docker and Containers

🇬🇧 English Definition

Containers package applications with dependencies while sharing the host Linux kernel, isolating application environments efficiently.

🇮🇳 Hinglish Definition

Container application ko dependencies ke saath isolated environment me run karta hai aur host kernel share karta hai.

💻 Docker Container Management Commands Created by Gagan Sir

docker pull nginx
docker run -d --name web -p 8080:80 nginx
docker exec -it web sh
docker logs web

Module 44: L1/L2/L3 Interview Preparation & Final Revision

🇬🇧 English Definition

Structured interview preparation framing answers using the Golden Framework: Impact -> Evidence -> Isolation -> Safe Remediation -> Validation -> Prevention.

🇮🇳 Hinglish Definition

Interview me Answer Structure: Pehle Impact batao, phir Evidence, failing layer Isolate karo, Safe Fix do, Result Validate karo aur last me Root Cause Prevention explain karo.
