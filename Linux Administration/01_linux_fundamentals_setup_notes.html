Module 1: Linux Fundamentals & Operating System Kernel

Understanding the Linux kernel architecture, distributions, and shell environment.

🇬🇧 English Definition

Linux is an open-source Unix-like kernel. A Linux distribution combines the kernel with user-space utilities, system libraries, package management, and application software.

🇮🇳 Hinglish Definition

Linux ek open-source Unix-like kernel hai. Distribution me kernel ke saath utilities, libraries, package manager aur applications milkar complete operating environment banta hai.

Core Concepts & Rules

  • Kernel: Core component managing CPU, RAM, devices, process scheduling, and filesystems.
  • Shell & Bash: Bourne Again Shell (Bash) acts as the CLI command interpreter between user and kernel.
  • Root & Sudo: Root is the superuser account; sudo grants temporary root elevation for administrative tasks.

🔍 Line-by-Line Command Breakdown

  1. Line 1: pwd prints current working directory path.
  2. Line 2: ls -lah lists all files including hidden ones with human-readable sizes.
  3. Line 3: whoami prints current logged-in user name.
  4. Line 4: echo $PATH outputs environment PATH executable search directories.
  5. Line 5: alias ll='ls -lah' creates shortcut alias for detailed listing.

🎯 Interview Focus & Questions

  • Q: What is Linux?
    A: Linux is an open-source Unix-like kernel; distributions package it with user-space software.
  • Q: What is a kernel?
    A: The core component that manages CPU, memory, devices, processes, filesystems and networking.
  • Q: What is Bash?
    A: Bash means Bourne Again Shell and is a widely used Linux shell interpreter.
  • Q: What is sudo?
    A: sudo allows an authorized user to run commands with elevated root privileges.

Module 2: Installation, VMs and Initial Setup

Setting up Linux Virtual Machines (VMs), storage allocation, and network interfaces.

🇬🇧 English Definition

Practice Linux first in a Virtual Machine (VM). Understand ISO installation, BIOS/UEFI boot modes, CPU/RAM resource allocation, virtual disks, NAT vs Bridged networking, and updates.

🇮🇳 Hinglish Definition

Linux ko pehle VirtualBox, VMware ya Hyper-V VM me install karke practice karo. Production server par direct experiments avoid karo.

Core Concepts & Rules

  • NAT Networking: Provides internet connectivity through host machine IP translation.
  • Bridged Networking: Places VM directly onto the same physical network subnet as host.
  • System updates: Use system package manager (apt/dnf) to update installed software repositories.

🔍 Line-by-Line Command Breakdown

  1. Line 1: hostnamectl displays or updates system hostname and OS details.
  2. Line 2: timedatectl configures system clock time and timezone settings.
  3. Line 3: ip addr shows all network interface IP addresses.
  4. Line 4: sudo apt update refreshes package repository index lists.

🎯 Interview Focus & Questions

  • Q: Why use a VM for practice?
    A: A VM gives an isolated environment for safe Linux administration practice.
  • Q: NAT vs Bridged networking?
    A: NAT provides connectivity through the host; Bridged places the VM on the same network as the host.
