Unit 4: Email, Cloud & Cyber Security

Chapter 22: Email

Hinglish Explanation: Email me sender, recipient, subject, body aur attachments ho sakte hain.
  • To = primary recipient; CC = visible copy; BCC = hidden copy.
  • Attachment adds a file to the message.
  • Spam is unwanted bulk communication.
  • Phishing emails try to trick users into revealing information or clicking malicious links.

Chapter 23: Cloud Computing

English Definition: Cloud computing provides computing resources such as storage, processing and software over a network on demand.

Hinglish Explanation: Cloud me resources local computer ke bajay remote data centers se Internet/network ke through milte hain.
ModelProvidesExample concept
IaaSVMs/storage/networkInfrastructure
PaaSApp platformDevelopment environment

Trick:
SaaS provides ready-to-use software (like Google Docs). IaaS provides raw infrastructure.

Chapter 24: Cyber Security Fundamentals

  • CIA triad: Confidentiality, Integrity, Availability.
  • Authentication verifies identity (Who are you?); authorization determines permissions (What can you access?).
  • Least privilege gives only required access.

Chapter 26: Phishing, Spoofing & Social Eng.

  • Phishing: deceptive messages/links.
  • Spear phishing: targeted phishing.
  • Smishing: SMS-based phishing.
  • Vishing: voice-call phishing.
  • Spoofing: impersonates an address, identity, website or communication source.

📝 SSC Practice MCQs (Unit 4)

SSC CGL

Q1. Which protocol is commonly used to send email?

  • A. SMTP
  • B. HTTP
  • C. FTP
  • D. DNS
Answer: A. SMTP
Solution: SMTP (Simple Mail Transfer Protocol) is used for sending email.
SSC CHSL

Q2. Which malware can self-propagate across networks?

  • A. Worm
  • B. Trojan
  • C. Adware
  • D. Cookie
Answer: A. Worm
Solution: A worm can replicate and self-propagate across networks without needing a host file (unlike a virus).
SSC MTS

Q3. Which attack commonly uses deceptive messages and links?

  • A. Phishing
  • B. Defragmentation
  • C. Formatting
  • D. Indexing
Answer: A. Phishing
Solution: Phishing is a social engineering attack that uses deceptive emails/messages to steal user data.
SSC CPO

Q4. Which cloud model provides ready-to-use software?

  • A. IaaS
  • B. PaaS
  • C. SaaS
  • D. BIOS
Answer: C. SaaS
Solution: SaaS (Software as a Service) provides ready-to-use applications over the internet (e.g., Google Workspace).
SSC Selection Post

Q5. What does MFA improve?

  • A. Authentication security
  • B. Printer speed
  • C. Screen size
  • D. Storage capacity
Answer: A. Authentication security
Solution: MFA (Multi-Factor Authentication) requires multiple forms of verification, greatly improving authentication security.
