Rapid Revision — SSC Computer One-Liners

These are designed for last-day and last-hour revision.
1. CPU is commonly called the brain of a computer.
2. ALU performs arithmetic and logical operations.
3. RAM is volatile memory.
4. ROM is non-volatile memory.
5. 1 byte = 8 bits.
6. Binary number system has base 2.
7. Hexadecimal has base 16.
8. BIOS/UEFI helps initialize hardware during boot.
9. Windows is an operating system, not a programming language.
10. Linux is an operating-system family/kernel ecosystem widely used on servers.
11. Keyboard is an input device; Monitor is an output device.
12. Touchscreen can provide both input and output.
13. OCR converts printed characters into machine-readable text.
14. MICR is associated with magnetic-ink character recognition.
15. IPv4 uses 32-bit addresses; IPv6 uses 128-bit addresses.
16. TCP is connection-oriented and reliable.
17. UDP is connectionless and has lower overhead.
18. SMTP is used for sending email. IMAP/POP3 for receiving.
19. SaaS provides ready-to-use software as a service.
20. CIA stands for Confidentiality, Integrity and Availability.
21. Ransomware commonly encrypts or blocks access to data.
22. Phishing targets users with deceptive messages.
23. Excel formulas generally begin with =.
24. Algorithm is a finite sequence of steps to solve a problem.
25. Flowchart diamond commonly represents a decision.

📝 SSC Practice MCQs (Final Test)

SSC CGL

Q1. Which key combination pastes content?

  • A. Ctrl+V
  • B. Ctrl+S
  • C. Ctrl+Z
  • D. Ctrl+F
Answer: A. Ctrl+V
Solution: Ctrl+V is used to paste copied or cut content.
SSC CHSL

Q2. Which is a presentation file extension?

  • A. .pptx
  • B. .xlsx
  • C. .docx
  • D. .csv
Answer: A. .pptx
Solution: .pptx is used for MS PowerPoint presentations. .xlsx is Excel, .docx is Word.
SSC CPO

Q3. Which is non-volatile?

  • A. RAM
  • B. Cache
  • C. Register
  • D. ROM
Answer: D. ROM
Solution: ROM (Read Only Memory) does not lose its contents when the power is turned off.
