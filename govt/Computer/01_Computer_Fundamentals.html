Unit 1: Computer Fundamentals

Chapter 1: Computer Fundamentals

English Definition: A computer is an electronic programmable machine that accepts data, processes it according to instructions, stores it and produces information.

Hinglish Explanation: Computer ko simple language me ek electronic machine samjho jo input leta hai, instructions ke according processing karta hai, data store karta hai aur output deta hai.

Important Points

  • Data = raw facts; Information = processed meaningful data.
  • Basic cycle: Input → Processing → Output → Storage.
  • Characteristics: speed, accuracy, storage, automation, diligence and versatility.
  • Hardware = physical components; Software = programs/instructions.

Chapter 3: Computer Architecture & CPU

Hinglish Explanation: CPU ko computer ka brain bola jata hai. Ye instructions ko fetch, decode aur execute karta hai.
  • CPU contains: ALU, Control Unit and registers.
  • ALU: Performs arithmetic and logical operations.
  • Control Unit (CU): Coordinates instruction execution.
  • Registers: Very fast small storage locations inside CPU.
  • Clock speed: commonly expressed in Hz, MHz or GHz.
ComponentFunction
ALUArithmetic + logic operations

Chapter 4: Memory & Storage

Hinglish Explanation: RAM temporary working memory hai; ROM generally non-volatile firmware storage hai. Storage devices data ko long term ke liye rakhte hain.
  • Primary memory: registers, cache, RAM, ROM.
  • RAM is volatile: contents are lost when power is removed.
  • ROM is non-volatile: firmware/boot instructions are commonly stored here.
  • Cache: faster than RAM and closer to CPU.
  • Secondary storage: HDD, SSD, optical media and flash drives.
  • Units: bit, byte, KB, MB, GB, TB; 1 byte = 8 bits.
MemoryVolatile?Typical use
RegisterYesImmediate CPU work
CacheYesSpeed up CPU access
RAMYesRunning programs
ROMNoFirmware/boot
SSD/HDDNoLong-term storage

Chapter 5: Input & Output Devices

  • Input: keyboard, mouse, scanner, microphone, webcam, joystick, barcode reader, biometric devices.
  • Output: monitor, printer, speakers, projector, plotter.
  • Both: Touchscreen can act as both input and output.
  • OCR: converts printed characters into editable text.
  • OMR: reads marked responses.
  • MICR: used for magnetic-ink character recognition in banking.

Hinglish Explanation: Motherboard ko main board samjho jisme CPU, memory slots, expansion slots aur connectors connected hote hain.

📝 SSC Practice MCQs (Unit 1)

SSC CGL

Q1. Which unit performs arithmetic and logical operations?

  • A. ALU
  • B. CU
  • C. RAM
  • D. ROM
Answer: A. ALU
Solution: The Arithmetic Logic Unit (ALU) is the part of the CPU responsible for all mathematical calculations and logical comparisons.
SSC CHSL

Q2. Which memory is volatile?

  • A. ROM
  • B. RAM
  • C. DVD
  • D. SSD
Answer: B. RAM
Solution: RAM (Random Access Memory) is volatile, meaning it loses its data when the computer is turned off.
SSC MTS

Q3. Which is an input device?

  • A. Monitor
  • B. Printer
  • C. Keyboard
  • D. Speaker
Answer: C. Keyboard
Solution: Keyboard is an input device used to enter data. Monitor, Printer, and Speaker are output devices.
SSC Steno

Q4. Which technology is used to read printed characters?

  • A. OCR
  • B. OMR
  • C. MICR
  • D. BIOS
Answer: A. OCR
Solution: OCR (Optical Character Recognition) converts printed characters into machine-readable editable text.
