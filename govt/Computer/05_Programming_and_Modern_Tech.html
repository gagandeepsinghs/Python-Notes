Unit 5: Programming & Modern Tech

Chapter 27: Encryption & Authentication

Hinglish Explanation: Encryption data ko unreadable form me convert karta hai. Digital signature document/message ki authenticity aur integrity verify karne me help karta hai.
  • Symmetric encryption: uses one shared key for encryption/decryption.
  • Asymmetric cryptography: uses public/private key pairs.
  • Hashing: produces a fixed-size digest and is designed to be one-way.
  • MFA: uses more than one authentication factor.

Chapter 29: Programming Fundamentals

  • Variable: stores a value/reference.
  • Data types: describe kinds of values.
  • Conditional statements: choose paths (e.g., if marks >= 40).
  • Loops: repeat instructions (e.g., for / while).
  • Function: groups reusable logic.
  • Bug: Program error.

Chapter 30: AI, ML & Generative AI

English Definition: AI is the broad field of building systems that perform tasks associated with human intelligence; ML learns patterns from data.

  • Supervised learning: uses labeled data.
  • Unsupervised learning: finds patterns without target labels.
  • Generative AI: can produce text, images, audio or code.
  • Prompt: is an instruction/input given to a generative model.

Chapter 31: Cyber Hygiene & Safe Computing

Hinglish Explanation: Daily safe habits cyber attacks ka risk kaafi reduce kar sakte hain.
  • Use unique strong passwords and a password manager.
  • Enable MFA (Stops many account takeover attempts).
  • Keep OS/apps/browser updated (Patch vulnerabilities).
  • Back up important data (Recovery).
  • Verify URLs and senders before clicking (Avoid phishing).

📝 SSC Practice MCQs (Unit 5)

SSC CGL

Q1. Which flowchart symbol represents a decision?

  • A. Oval
  • B. Rectangle
  • C. Diamond
  • D. Circle
Answer: C. Diamond
Solution: The diamond shape in a flowchart represents a decision point (e.g., Yes/No, True/False).
SSC CHSL

Q2. Which is a primary key property?

  • A. Can identify a record uniquely
  • B. Must always be text
  • C. Stores images only
  • D. Deletes a table
Answer: A. Can identify a record uniquely
Solution: A primary key is a field in a database table that uniquely identifies each row/record.
SSC CPO

Q3. Which type of learning uses labeled data?

  • A. Unsupervised learning
  • B. Supervised learning
  • C. Generative AI
  • D. Deep learning
Answer: B. Supervised learning
Solution: Supervised learning requires labeled data to train the model, whereas unsupervised learning looks for patterns in unlabeled data.
