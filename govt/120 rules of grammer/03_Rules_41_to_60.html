Unit 3: Rules 41–60 (Gerunds, Infinitives, Modals & Base Tenses)

Rule 41: Interested in

English Rule: Interested + in.

Hinglish: Interested ke baad in.
Example: He is interested in music.
Rule 42: Capable of

English Rule: Capable + of + noun/gerund.

Hinglish: Capable of doing.
Example: She is capable of solving it.
Rule 43: Accustomed to

English Rule: Be accustomed to + noun/gerund.

Hinglish: 'To' yahan preposition hai.
Example: He is accustomed to working late.
Watch out! Many students mistakenly put V1 after "accustomed to". It takes V-ing (gerund).
Rule 44: Look forward to

English Rule: Look forward to + noun/gerund.

Hinglish: 'To' ke baad V-ing.
Example: I look forward to meeting you.
Rule 45: Used to vs Be used to

English Rule: Used to + V1 = past habit; be used to + noun/V-ing = accustomed.

Hinglish: Dono ka meaning/form alag.
Example: He used to play. He is used to playing.
Rule 46: Would rather

English Rule: Would rather + base verb.

Hinglish: Would rather ke baad V1.
Example: I would rather stay.
Rule 47: Had better

English Rule: Had better + base verb.

Hinglish: Had better ke baad V1.
Example: You had better leave.
Rule 48: Let

English Rule: Let + object + base verb.

Hinglish: Let ke baad object + V1.
Example: Let me go.
Rule 49: Make/Have/Help

English Rule: Causative structures can use object + base verb; passive 'make' commonly uses 'to'.

Hinglish: Make me laugh; was made to laugh.
Example: She made me laugh.
Rule 50: Gerund after preposition

English Rule: Verb after a preposition generally takes -ing.

Hinglish: Preposition ke baad V-ing.
Example: He is fond of reading.
Rule 51: Enjoy / Avoid / Mind

English Rule: These are commonly followed by gerund.

Hinglish: Inke baad V-ing.
Example: I enjoy reading.
Rule 52: Infinitive purpose

English Rule: To + V1 can show purpose.

Hinglish: Purpose ke liye to + V1.
Example: He went to buy milk.
Rule 53: Stop doing / Stop to do

English Rule: Stop doing = cease activity; stop to do = pause to perform another action.

Hinglish: Meaning change hota hai.
Example: He stopped smoking. He stopped to rest.
Rule 54: Remember doing / to do

English Rule: Remember doing = recalls past event; remember to do = means do not forget.

Hinglish: Gerund vs infinitive meaning change.
Example: I remember meeting him. Remember to call.
Rule 55: Try doing / to do

English Rule: Try doing = experiment; try to do = make an effort.

Hinglish: Meaning change.
Example: Try restarting. Try to solve it.
Rule 56: Modal verbs

English Rule: Modal + base verb.

Hinglish: Can/could/may/might/must/should/will/would ke baad V1.
Example: He can swim.
Rule 57: Need/Dare

English Rule: When modal-like, need/dare can take base verb without to.

Hinglish: Need not go; dare not ask.
Example: Context matters. You need not go.
Rule 58: Do/Does/Did

English Rule: After do/does/did use base verb.

Hinglish: Helping verb ke baad V1.
Example: Did he go?
Did he "went" is a very common trap.
Rule 59: Present Simple

English Rule: V1; he/she/it takes s/es.

Hinglish: Routine/fact tense.
Example: He works. They work.
Rule 60: Present Continuous

English Rule: am/is/are + V-ing.

Hinglish: Abhi/around now action.
Example: She is reading.
