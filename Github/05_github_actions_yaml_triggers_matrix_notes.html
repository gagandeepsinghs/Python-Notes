GitHub Actions Architecture
🇬🇧 English Definition
GitHub Actions is an automated workflow engine integrated into GitHub. Workflows are declared in YAML under `.github/workflows/`. Workflows respond to events, execute jobs on runners, and run sequential steps.
🇮🇳 Hinglish Definition
GitHub Actions GitHub ka builtin automation engine hai. Event trigger hone par YAML workflow runner machine par jobs aur steps automatically run karta hai.
