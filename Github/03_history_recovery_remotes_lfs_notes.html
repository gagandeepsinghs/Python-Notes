Restore vs Reset vs Revert
GoalCommandBest Use Case & Safety
Discard file changesgit restore fileUnstaged local changes
Unstage filegit restore --staged fileRemove file from staging index
Undo shared commitgit revert SHASafe for team/remote history
Move HEAD, keep changesgit reset --soft HEAD~1Local history cleanup
Move HEAD and indexgit reset HEAD~1Local history cleanup
Discard local changesgit reset --hard HEAD~1Dangerous; rewrites history permanently
git restore app.py git restore --staged app.py git revert abc1234 git reset --soft HEAD~1 git reset HEAD~1 git reset --hard HEAD~1

Reflog and Recovery
🇬🇧 English Definition
Git reflog (reference log) records every movement of HEAD and local branch pointers. It allows recovering lost commits, deleted branches, or aborted rebases.
🇮🇳 Hinglish Definition
Reflog Git ke sabhi local pointer movements ka record rakhta hai. Galti se reset ya branch delete hone par reflog se exact SHA dhoondh kar recover kar sakte hain.
git reflog git reflog show main // Recover lost commit by creating a new branch at lost SHA git switch -c recovery_branch abc1234 git show abc1234

Advanced Git Tools (Cherry-pick, Bisect, Worktree, Rerere)
CommandPurposeTypical Use Case
git cherry-pickApply specific commit to current branchBackport hotfix from main to release branch
git bisectBinary search commit historyFind exact commit that introduced a bug regression
git worktreeMultiple working directories attached to single repoWork on feature and hotfix concurrently
git rerereReuse recorded resolution of conflicted mergesRepeated conflict resolution during rebases
git range-diffCompare two commit seriesReview interactive rebase changes
// Cherry pick git cherry-pick abc1234 // Bisect binary search git bisect start git bisect bad git bisect good v1.0.0 // test project git bisect good // or git bisect bad git bisect reset // Worktree git worktree add ../hotfix hotfix/payment git worktree list git worktree remove ../hotfix
