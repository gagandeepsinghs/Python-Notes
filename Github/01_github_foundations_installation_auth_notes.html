Git and GitHub Fundamentals & Mental Model
🇬🇧 English Definition
Git is a distributed version-control system that tracks local file changes, commits, and branch history. GitHub is a cloud hosting platform for Git repositories that adds collaboration tools like Pull Requests, Code Review, Issues, Actions CI/CD, and Security scanning.
🇮🇳 Hinglish Definition
Git tumhare local machine par code changes aur history ko track karta hai. GitHub isi code ko online host karke team collaboration, review aur automation provide karta hai.
