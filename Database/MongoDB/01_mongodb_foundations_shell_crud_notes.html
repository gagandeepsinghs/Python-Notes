MongoDB Mental Model & SQL Comparison
🇬🇧 English Definition
MongoDB is a document-oriented NoSQL database storing flexible BSON records. Unlike relational databases, MongoDB organizes documents inside collections.
🇮🇳 Hinglish Definition
MongoDB ko samajhne ka easiest framework hai: Database → Collection → Document → Field.
SQL ConceptMongoDB ConceptMeaning
DatabaseDatabaseContainer
TableCollectionGroup of records/documents
RowDocumentOne BSON record
ColumnFieldOne key-value property
JOIN$lookup / Data ModelingCombine referenced data when needed
GROUP BY$groupAggregation grouping
WHEREQuery filter / $matchFilter documents
ORDER BYsort() / $sortOrder results

Installation & Starting MongoDB
// Shell version check mongosh --version // Connect to default server mongosh "mongodb://localhost:27017" // Run daemon manually mongod --dbpath /path/to/data
🔍 Line-by-Line Breakdown
  • `mongod`: The background database server daemon process.
  • `mongosh`: Interactive client shell for database queries and administration.

Insert Commands — insertOne & insertMany
// Single insert db.students.insertOne({ name: "Aman", age: 22, course: "MCA" }) // Batch insert db.students.insertMany([ { name: "Aman", age: 22, course: "MCA" }, { name: "Riya", age: 21, course: "BCA" } ]) // Unordered batch insert db.students.insertMany( [{ name: "A" }, { name: "B" }], { ordered: false } )

Read / Find Syntax & Projection
db.students.find() db.students.find({ age: 22 }) db.students.findOne({ name: "Aman" }) db.students.find({ age: { $gte: 18 } }) db.students.find( { course: "MCA" }, { name: 1, age: 1, _id: 0 } )
