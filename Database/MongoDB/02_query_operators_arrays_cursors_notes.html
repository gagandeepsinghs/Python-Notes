Equality & Comparison Operators
OperatorSyntax ExampleMeaning
$eq{age: {$eq: 22}}Equals
$ne{age: {$ne: 22}}Not equal
$gt{age: {$gt: 22}}Greater than
$gte{age: {$gte: 22}}Greater or equal
$lt{age: {$lt: 22}}Less than
$lte{age: {$lte: 22}}Less or equal
$in{city: {$in: ['Delhi','Ludhiana']}}Matches any in array
$nin{city: {$nin: ['Delhi','Mumbai']}}Matches none in array
8
Logical Operators ($and, $or, $nor, $not)
// AND — Implicit db.students.find({ age: { $gte: 18 }, course: "MCA" }) // OR db.students.find({ $or: [ { city: "Ludhiana" }, { city: "Chandigarh" } ] }) // AND — Explicit db.students.find({ $and: [ { age: { $gte: 18 } }, { course: "MCA" } ] }) // NOR db.students.find({ $nor: [ { city: "Delhi" }, { city: "Mumbai" } ] }) // NOT db.students.find({ age: { $not: { $gt: 30 } } })
9
Element Operators ($exists, $type)
db.students.find({ phone: { $exists: true } }) db.students.find({ phone: { $exists: false } }) db.students.find({ age: { $type: "int" } })
10
Null & Missing Fields
// Matches both null value and missing field db.students.find({ phone: null }) // Matches strictly missing field db.students.find({ phone: { $exists: false } })
11
Regex / Pattern Queries
// Starts with 'A' db.students.find({ name: { $regex: "^A" } }) // Case-insensitive regex matching "an" db.students.find({ name: { $regex: "an", $options: "i" } })
12
Array Queries ($all, $size, $elemMatch)
// Contains element db.students.find({ skills: "Python" }) // Contains ALL elements db.students.find({ skills: { $all: ["Python", "MongoDB"] } }) // Array size check db.students.find({ skills: { $size: 2 } }) // Element match condition db.students.find({ skills: { $elemMatch: { $eq: "Python" } } })
13
Embedded Document Queries (Dot Notation)
db.students.find({ "address.city": "Ludhiana" }) db.students.find({ "address.pin": { $gte: 141000 } })
14
Query Cursor Methods
// Sorting (-1 descending, 1 ascending) db.students.find().sort({ age: -1 }) // Pagination limits db.students.find().limit(10) db.students.find().skip(20) // Document counting & distinct values db.students.countDocuments({ course: "MCA" }) db.students.distinct("city") // Iterate cursor with forEach db.students.find().forEach(x => print(x))
