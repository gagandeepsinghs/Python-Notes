Update Operators
OperatorExampleUse Case
$set{$set: {city: 'Delhi'}}Set or change field value
$unset{$unset: {temp: ''}}Remove field from document
$inc{$inc: {age: 1}}Increment / decrement number
$mul{$mul: {price: 1.1}}Multiply number field
$min{$min: {score: 50}}Update only if smaller
$max{$max: {score: 90}}Update only if larger
$rename{$rename: {'old': 'new'}}Rename field key
$push{$push: {skills: 'SQL'}}Append item to array
$addToSet{$addToSet: {skills: 'SQL'}}Append item only if unique
$pop{$pop: {skills: 1}}Remove first (-1) or last (1) item
$pull{$pull: {skills: 'SQL'}}Remove matching items from array
$pullAll{$pullAll: {skills: ['SQL','Python']}}Remove all listed items

Update One / Many / Replace
db.students.updateOne( { name: "Aman" }, { $set: { city: "Ludhiana" } } ) db.students.updateMany( { course: "MCA" }, { $inc: { age: 1 } } ) db.students.replaceOne( { name: "Aman" }, { name: "Aman", age: 23, course: "MCA" } )

Upsert Pattern
db.students.updateOne( { email: "aman@example.com" }, { $set: { name: "Aman", age: 22 } }, { upsert: true } )

Delete Commands

Atomic Find and Modify Helpers
db.students.findOneAndUpdate( { email: "aman@example.com" }, { $set: { verified: true } }, { returnDocument: "after" } ) db.students.findOneAndDelete({ email: "old@example.com" }) db.students.findOneAndReplace( { email: "aman@example.com" }, { email: "aman@example.com", name: "Aman", age: 23 } )

Bulk Write Operations
