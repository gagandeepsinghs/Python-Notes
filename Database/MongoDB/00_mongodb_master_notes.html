MongoDB Mental Model & SQL Comparison
🇬🇧 English Definition
MongoDB is a document-oriented NoSQL database storing flexible BSON records. Unlike relational databases, MongoDB organizes documents inside collections.
🇮🇳 Hinglish Definition
MongoDB ko samajhne ka easiest framework hai: Database → Collection → Document → Field.
SQL ConceptMongoDB ConceptMeaning
DatabaseDatabaseContainer
TableCollectionGroup of records/documents
RowDocumentOne BSON record
ColumnFieldOne key-value property
JOIN$lookup / Data ModelingCombine referenced data when needed
GROUP BY$groupAggregation grouping
WHEREQuery filter / $matchFilter documents
ORDER BYsort() / $sortOrder results

Logical Operators ($and, $or, $nor, $not)
// AND — Implicit db.students.find({ age: { $gte: 18 }, course: "MCA" }) // OR db.students.find({ $or: [ { city: "Ludhiana" }, { city: "Chandigarh" } ] }) // AND — Explicit db.students.find({ $and: [ { age: { $gte: 18 } }, { course: "MCA" } ] }) // NOR db.students.find({ $nor: [ { city: "Delhi" }, { city: "Mumbai" } ] }) // NOT db.students.find({ age: { $not: { $gt: 30 } } })

StagePurpose / Function

$projectSelect/compute fields
$set / $addFieldsAdd or modify fields

$groupGroup and calculate aggregates ($sum, $avg, $max, $min)

Performance Checklist
📋 12-Step Query Tuning Protocol
  • 1. Reproduce the slow query in a non-production test environment.
  • 2. Run `explain('executionStats')` to inspect query execution metrics.
  • 3. Check index usage (IXSCAN vs COLLSCAN).
  • 4. Compare total documents examined vs documents returned.
  • 5. Check sort behavior (in-memory sort vs index sort).
  • 6. Review projection to avoid unnecessary field transfers.
  • 7. Review schema and document size.
  • 8. Check server CPU / memory / disk I/O metrics.
  • 9. Check connection pool size and driver settings.
  • 10. Apply one controlled index or query structure change at a time.
  • 11. Re-test execution stats to confirm improvement.
  • 12. Monitor production performance metrics continuous feedback.

Interview Question Bank (35 Questions)
❓ Core Concept Interview Q&A
  • Q: What is BSON? Binary JSON storing typed key-value pairs (e.g., Date, ObjectId, Int64).
  • Q: `insertOne` vs `insertMany`? `insertOne` writes single doc; `insertMany` writes array batch with optional `{ordered: false}`.
  • Q: Difference between `updateOne` and `replaceOne`? `updateOne` modifies specific fields via `$set`/`$inc`, while `replaceOne` overwrites entire matching document.
  • Q: What is an index scan vs collection scan? IXSCAN uses index B-tree; COLLSCAN scans every document sequentially (slow).
  • Q: How does `$lookup` work? Performs left outer join between local collection field and foreign collection field.
  • Q: What are Change Streams? Real-time notification mechanism listening to collection changes via `watch()`.
