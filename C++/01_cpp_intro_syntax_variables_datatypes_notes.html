Module 1: C++ Language Overview & I/O Streams

C++ is a powerful, general-purpose programming language created by Bjarne Stroustrup as an extension of the C language with Object-Oriented features.

🇬🇧 English Definition

C++ is a compiled, statically-typed, multi-paradigm language offering low-level memory manipulation alongside high-level OOP abstractions.

🇮🇳 Hinglish Definition

C++ ko Bjarne Stroustrup ne C language me Object-Oriented Features (Classes & Objects) add karke banaya tha. Ye fast performance aur high-level design dono deti hai.

Core Concepts & Rules

  • std::cout (Console Output) uses stream insertion operator (<<).
  • std::cin (Console Input) uses stream extraction operator (>>).
  • using namespace std; avoids repeating std:: prefix before cout and endl.

🔍 Line-by-Line Code Breakdown

  1. Line 1: // iostream header included for standard I/O stream streams.
  2. Line 2: using namespace std; brings standard C++ names into scope.
  3. Line 4: int main() is the execution entry point function.
  4. Line 5: cout << prints text to terminal screen with endl newline.

Module 2: Reference Variables (&) vs Pointers (*)

Creating aliases for existing variables vs storing raw memory addresses.

🇬🇧 English Definition

A Reference in C++ is an alias (another name) for an existing variable, while a Pointer is a variable that stores a memory address.

🇮🇳 Hinglish Definition

Reference (&) variable ka ek dusra urf-naam (alias) hota hai. Pointer (*) RAM memory location ka address store karta hai.

Core Concepts & Rules

  • Reference Syntax: int &ref = originalVar; (Cannot be null and cannot be re-bound).
  • Pointer Syntax: int *ptr = &originalVar; (Can be null and re-pointed).
  • Modifying reference modifies original variable directly.

🔍 Line-by-Line Code Breakdown

  1. Line 2: Declare int val = 50.
  2. Line 3: Declare reference int &ref = val (ref is alias for val).
  3. Line 4: Modify ref = 100.
  4. Line 5: Prints val -> outputs 100 because ref modified underlying memory!
💻 Practical C++ Code Example - Reference Variables (&) vs Pointers (*) Created by Gagan Sir 
using namespace std;

int main() {
    int val = 50;
    int &ref = val; // Reference alias
    ref = 100;

    cout << "Original val value: " << val << endl;
    cout << "Reference ref value: " << ref << endl;
    return 0;
}
📤 Compiled C++ Output:
Original val value: 100 Reference ref value: 100
