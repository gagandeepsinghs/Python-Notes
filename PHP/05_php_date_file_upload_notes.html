Module 1: PHP Date & Time API

Formatting timestamps and parsing dates.

Core Theory & Principles

  • date(format, timestamp): Y-m-d H:i:s formats date string.
  • time(): returns current Unix timestamp.
  • date_default_timezone_set('Asia/Kolkata') sets active timezone.
  • strtotime('next Monday'): converts human readable date string into Unix timestamp.

Practical Key Takeaways

Mastering PHP Date & Time API builds fundamental development capability. Review practical code and outputs carefully.

💻 Practical Code Example - PHP Date & Time API Created by Gagan Sir 
<?php
date_default_timezone_set("Asia/Kolkata");
echo "Formatted Date: " . date("Y-m-d H:i:s") . "\n";
echo "Current Day: " . date("l") . "\n";

$nextWeek = strtotime("+1 week");
echo "Next Week Date: " . date("Y-m-d", $nextWeek) . "\n";
?>
📤 Expected Output / Browser Rendered Result:
Formatted Date: 2026-10-03 00:15:00 Current Day: Saturday Next Week Date: 2026-10-10

Module 2: Include/Require & File Handling (I/O)

Modular code inclusion and file read/write operations.

Core Theory & Principles

  • include vs require: include produces a Warning on missing file; require produces a Fatal Error halting script execution.
  • include_once / require_once ensures file is included only once.
  • file_get_contents($file) reads entire file into string.
  • file_put_contents($file, $data, FILE_APPEND) writes data to file.
  • fopen(), fread(), fwrite(), fclose() provide fine-grained stream control.

Practical Key Takeaways

Mastering Include/Require & File Handling (I/O) builds fundamental development capability. Review practical code and outputs carefully.

💻 Practical Code Example - Include/Require & File Handling (I/O) Created by Gagan Sir 
<?php
$logFile = "server_log.txt";
$logEntry = "[" . date("Y-m-d H:i:s") . "] User login successful\n";

file_put_contents($logFile, $logEntry, FILE_APPEND);
echo "Log entry recorded successfully.\n";

if (file_exists($logFile)) {
    echo "File Size: " . filesize($logFile) . " bytes\n";
}
?>
📤 Expected Output / Browser Rendered Result:
Log entry recorded successfully. File Size: 48 bytes
