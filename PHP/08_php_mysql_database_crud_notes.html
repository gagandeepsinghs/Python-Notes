8. PHP MySQL Database Integration, PDO & CRUD Operations

Theory & Practical Manual: PDO connection, prepared statements, SQL injection prevention & CRUD (Create, Read, Update, Delete)

Module 1: PDO Database Connectivity & Prepared Statements

Connecting securely to MySQL databases using PHP Data Objects (PDO).

Core Theory & Principles

  • PDO (PHP Data Objects) supports 12+ database systems with a unified API.
  • Prepared Statements separate SQL query logic from user parameters, completely neutralizing SQL Injection attacks.
  • PDO Error Modes: PDO::ERRMODE_EXCEPTION throws catchable PDOExceptions.

Practical Key Takeaways

Mastering PDO Database Connectivity & Prepared Statements builds fundamental development capability. Review practical code and outputs carefully.

💻 Practical Code Example - PDO Database Connectivity & Prepared Statements 
<?php
$dsn = "mysql:host=localhost;dbname=school_db;charset=utf8mb4";
$user = "root";
$pass = "password";

try {
    $pdo = new PDO($dsn, $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC
    ]);
    echo "Database connected cleanly via PDO!\n";
} catch (PDOException $e) {
    echo "Connection status logged: Mock DB mode.\n";
}
?>
📤 Expected Output / Browser Rendered Result:
Database connected cleanly via PDO!

Module 2: CRUD Operations (Create, Read, Update, Delete)

Executing parameterized SQL queries safely.

Core Theory & Principles

  • INSERT INTO table (col1, col2) VALUES (:val1, :val2)
  • SELECT * FROM table WHERE id = :id
  • UPDATE table SET col1 = :val1 WHERE id = :id
