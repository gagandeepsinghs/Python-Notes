Module 1: PHP Architecture & Syntax Fundamentals

PHP (Hypertext Preprocessor) is a widely-used server-side scripting language embedded within HTML.

Core Theory & Principles

  • PHP code is executed on the web server, generating standard HTML sent to the client browser.
  • PHP scripts start with <?php and end with ?>.
  • Statements are terminated with semicolons (;).
  • echo and print output data. echo is slightly faster and accepts multiple arguments.
  • Single-line comments use // or /* */ multi-line comments. (Avoid hash symbol).

Practical Key Takeaways

Mastering PHP Architecture & Syntax Fundamentals builds fundamental development capability. Review practical code and outputs carefully.

Module 2: PHP Variables & Variable Scope (local, global, static)

Variables store data values starting with $ dollar sign.

Core Theory & Principles

  • Variable names start with $ followed by a letter or underscore (case-sensitive).
  • PHP is dynamically typed; variable types are determined automatically.
  • local scope: variables declared inside a function are accessible only within that function.
  • global scope: variables declared outside functions. Access inside functions using global keyword or $GLOBALS array.
  • static scope: static keyword retains variable value between function invocations.

Practical Key Takeaways

Mastering PHP Variables & Variable Scope (local, global, static) builds fundamental development capability. Review practical code and outputs carefully.

💻 Practical Code Example - PHP Variables & Variable Scope (local, global, static) Created by Gagan Sir 
<?php
$globalVar = 100; // Global Scope

function testScope() {
    global $globalVar;
    static $counter = 0; // Static Scope
    $counter++;
    $localVar = 50; // Local Scope
    echo "Counter: $counter | Global: $globalVar | Local: $localVar\n";
}

testScope();
testScope();
?>
📤 Expected Output / Browser Rendered Result:
Counter: 1 | Global: 100 | Local: 50 Counter: 2 | Global: 100 | Local: 50

Module 3: PHP Data Types & Operators

8 primitive and compound data types and arithmetic, comparison & logical operators.

Core Theory & Principles

  • Scalar types: String, Integer, Float (Double), Boolean.
  • Compound types: Array, Object.
  • Special types: NULL, Resource.
  • var_dump() outputs data type and value details.
  • Comparison operators: == (loose), === (identical value and type), !=, !==, <>, <=> (spaceship operator).

Practical Key Takeaways

Mastering PHP Data Types & Operators builds fundamental development capability. Review practical code and outputs carefully.

💻 Practical Code Example - PHP Data Types & Operators Created by Gagan Sir 
<?php
$str = "Gagan Sir";
$intVal = 42;
$floatVal = 99.99;
$isTrue = true;

var_dump($str);
var_dump($intVal);
var_dump($floatVal);
var_dump($isTrue);

// Spaceship Operator (<=>)
echo (10 <=> 20) . "\n"; // Returns -1
echo (20 <=> 20) . "\n"; // Returns 0
echo (30 <=> 20) . "\n"; // Returns 1
?>
📤 Expected Output / Browser Rendered Result:
string(9) "Gagan Sir" int(42) float(99.99) bool(true) -1 0 1
