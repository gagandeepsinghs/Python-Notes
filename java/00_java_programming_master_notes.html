Chapter 11: Four Pillars of OOP

🇬🇧 English Definition

Encapsulation, inheritance, polymorphism and abstraction are the core object-oriented principles structuring maintainable software components.

🇮🇳 Hinglish Definition

OOP ke 4 pillars hain: Encapsulation, Inheritance, Polymorphism aur Abstraction.

💻 Polymorphism & Method Overriding Example 
class Animal { void sound() { System.out.println("Animal sound"); } }
class Dog extends Animal { @Override void sound() { System.out.println("Bark"); } }

public class Main {
    public static void main(String[] args) {
        Animal a = new Dog();
        a.sound();
    }
}
📤 Execution Output:
Bark

Chapter 20: Stream API

🇬🇧 English Definition

Streams provide a declarative functional pipeline supporting filter, map, collect, and reduce aggregate operations on sequence data.

🇮🇳 Hinglish Definition

Stream API collection data ko pipeline ke through process karte hain filter, map aur collect operations se.

💻 Stream Filter & Map Pipeline Example 
import java.util.List;

public class StreamPipeline {
    public static void main(String[] args) {
        List nums = List.of(1, 2, 3, 4, 5);
        nums.stream().filter(n -> n % 2 == 0).map(n -> n * n).forEach(System.out::println);
    }
}
📤 Execution Output:
4 16

💻 Palindrome String Check Program 
public class PalindromeCheck {
    public static void main(String[] args) {

    }
}
📤 Execution Output:
