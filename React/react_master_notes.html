Chapter 1: React Architecture & Virtual DOM

🇬🇧 English Definition

React is an open-source, component-based JavaScript frontend library developed by Meta for building fast single-page user interfaces using an in-memory Virtual DOM.

🇮🇳 Hinglish Definition

React ek JavaScript library hai jise Facebook ne banaya hai. Ye web page ko components me divide karke super-fast Virtual DOM ke dwara render karti hai.

💻 React Entry Point (main.jsx) 
import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App.jsx";

const root = ReactDOM.createRoot(document.getElementById("root"));
root.render();
📤 Browser Output:
React App successfully mounted into DOM root element.
