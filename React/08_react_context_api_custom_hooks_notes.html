Module 1: The Prop Drilling Problem & Context Solution

Managing global state across deeply nested component hierarchies.

🇬🇧 English Definition

Prop Drilling occurs when props are passed down through multiple intermediate components that do not need the data themselves just to reach a deeply nested child.

🇮🇳 Hinglish Definition

Prop Drilling tab hoti hai jab kisi deeply nested child ko data dene ke liye beech ke saare unused components se props pass karni padti hai. Context API ise solve karta hai.

Core Concepts & Rules

  • Context provides a way to share values like user data, themes, or language settings globally.
  • Step 1: Create context with createContext().
  • Step 2: Wrap component tree with .
  • Step 3: Consume context in any descendant using useContext(Context).

Practical Takeaways & Best Practices

Mastering The Prop Drilling Problem & Context Solution builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - The Prop Drilling Problem & Context Solution 
import React, { createContext, useContext, useState } from "react";

// 1. Create Context
const ThemeContext = createContext();

export function ThemeProvider({ children }) {
  const [theme, setTheme] = useState("light");
  const toggleTheme = () => setTheme(prev => (prev === "light" ? "dark" : "light"));

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

// Child Consumer Component
export function ThemeButton() {
  const { theme, toggleTheme } = useContext(ThemeContext);
  return (
    <button onClick={toggleTheme}>
      Current Theme: {theme.toUpperCase()} (Click to Toggle)
    </button>
  );
}
📤 Expected Output / Browser UI Render:
Theme state consumed anywhere deep in component tree without passing props!

Module 2: Building Reusable Custom React Hooks

Extracting component logic into reusable JavaScript functions.

🇬🇧 English Definition

A Custom Hook is a JavaScript function whose name starts with 'use' and that may call other Hooks to share stateful logic between components.

🇮🇳 Hinglish Definition

Custom Hook ek simple function hota hai jiska naam 'use' se shuru hota hai. Iska maqsat reusable component logic ko alag jagah extract karke multiple components me use karna hai.

Core Concepts & Rules

  • Must start with prefix 'use' (e.g., useFetch, useLocalStorage, useWindowSize).
  • Custom hooks do NOT return JSX; they return state data or handler functions.
  • Each component using a custom hook gets completely isolated state.

Practical Takeaways & Best Practices

Mastering Building Reusable Custom React Hooks builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - Building Reusable Custom React Hooks 
// Custom Hook: useLocalStorage.js
import { useState, useEffect } from "react";

export function useLocalStorage(key, initialValue) {
  const [value, setValue] = useState(() => {
    const saved = localStorage.getItem(key);
    return saved ? JSON.parse(saved) : initialValue;
  });

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue];
}

// Usage inside component:
// const [name, setName] = useLocalStorage("username", "Instructor");

Custom Hook manages persistent LocalStorage binding seamlessly across page reloads!

Module 3: React Best Practices & Folder Structure

Scalable project organization for production-grade React applications.

🇬🇧 English Definition

Organizing React code into modular folders (components, hooks, context, pages, assets) maximizes codebase maintainability and team productivity.

🇮🇳 Hinglish Definition

React project ko hamesha systematic folder structure me divide kare: src/components, src/hooks, src/pages, src/context, src/utils.

Core Concepts & Rules

  • Keep components small and focused on a single responsibility.
  • Use index.js/jsx barrel exports for clean imports.
  • Use React.lazy and Suspense for code splitting large route pages.
