Module 1: Conditional Rendering Patterns in React

Displaying different JSX UI elements based on specific component state conditions.

🇬🇧 English Definition

Conditional Rendering in React allows developer logic to conditionally render specific elements or components depending on state or prop evaluations.

🇮🇳 Hinglish Definition

Conditional Rendering ka matlab hai condition ke aadhar par alag UI dikhana, jaise user logged in hai to Dashboard dikhao, varna Login Page.

Core Concepts & Rules

  • Ternary Operator (condition ? : ) for binary decisions.
  • Logical AND Operator (condition && ) when rendering UI only if true.
  • If/Else early returns inside function body before return statement.
  • Null return (return null;) hides component completely from rendering.

Practical Takeaways & Best Practices

Mastering Conditional Rendering Patterns in React builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - Conditional Rendering Patterns in React 
import React, { useState } from "react";

export default function LoginStatus() {
  const [isLoggedIn, setIsLoggedIn] = useState(false);

  return (
    <div>
      {isLoggedIn ? (
        <div>
          <h2>Welcome Back, Member!</h2>
          <button onClick={() => setIsLoggedIn(false)}>Logout</button>
        </div>
      ) : (
        <div>
          <h2>Please Sign In</h2>
          <button onClick={() => setIsLoggedIn(true)}>Login Now</button>
        </div>
      )}
      {isLoggedIn && <p style={{ color: "green" }}>Session Token Active</p>}
    </div>
  );
}
📤 Expected Output / Browser UI Render:
Initial state: Please Sign In [Button: Login Now] After Click: Welcome Back, Member! [Session Token Active]

Module 2: Rendering Data Lists with JavaScript Array map()

Transforming data arrays into collections of JSX elements efficiently.

🇬🇧 English Definition

Array.prototype.map() is the standard functional method in React used to iterate over a data array and return a list of rendered JSX elements.

🇮🇳 Hinglish Definition

React me array items ko UI me dikhane ke liye JS ke map() method ka use hota hai jo har element ko ek JSX element me convert karta hai.

Core Concepts & Rules

  • map() returns a new array of JSX items.
  • Data can be filtered before mapping using array.filter().map().
  • Keep list rendering logic inside clean helper components when complex.

Practical Takeaways & Best Practices

Mastering Rendering Data Lists with JavaScript Array map() builds clean, modular React application logic. Study code examples and definitions carefully.

Module 3: The Key Prop & React List Reconciliation

Why unique key attributes are mandatory when rendering dynamic lists in React.

🇬🇧 English Definition

A key is a special string attribute you must include when creating lists of elements to help React identify which items have changed, been added, or removed.

🇮🇳 Hinglish Definition

List items me key prop DSI (DOM Difference) identity ke liye zaroori hota hai. Key se React pata lagata hai ki kaunsa item change ya move hua hai.

Core Concepts & Rules

  • Keys MUST be unique among siblings (use database IDs or unique item codes).
  • Avoid using array indexes (map((item, index) => ...)) if list items can re-order or delete.
  • Keys are consumed internally by React and NOT passed down as props to children.

Practical Takeaways & Best Practices

Mastering The Key Prop & React List Reconciliation builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - The Key Prop & React List Reconciliation 
import React, { useState } from "react";

export default function DynamicList() {
  const [items, setItems] = useState([
    { id: "a1", text: "Master HTML & CSS" },
    { id: "b2", text: "Master JavaScript ES6+" }
  ]);

  const addItem = () => {
    const newItem = { id: Date.now().toString(), text: "Master React Framework" };
    setItems([newItem, ...items]);
  };

  return (
    <div>
      <button onClick={addItem}>Add React Course</button>
      <ul>
        {items.map(item => (
          <li key={item.id}>{item.text}</li>
        ))}
      </ul>
    </div>
  );
}
📤 Expected Output / Browser UI Render:
Click Button -> Master React Framework prepended cleanly with unique timestamp key.
