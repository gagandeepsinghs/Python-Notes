Module 1: React Props (Properties) & Data Passing

Props pass read-only data from parent components to child components.

🇬🇧 English Definition

Props (short for properties) are read-only input objects passed from parent to child components to dynamically customize their content and behavior.

🇮🇳 Hinglish Definition

Props wo variables ya data hote hai jo Parent Component dwara Child Component ko pass kiye jate hai. Child inko change (mutate) nahi kar sakta.

Core Concepts & Rules

  • Props flow strictly in a single direction (Uni-directional Data Flow: Parent -> Child).
  • Props are immutable; a child component cannot alter props it receives.
  • Destructuring props in function parameters keeps code clean.
  • Special prop children renders nested JSX content between component opening and closing tags.

Practical Takeaways & Best Practices

Mastering React Props (Properties) & Data Passing builds clean, modular React application logic. Study code examples and definitions carefully.

      <p>Duration: {duration} Hours</p>

      <div className="extra-info">{children}</div>

Module 2: React State & useState Hook

State allows React components to store dynamic data that triggers UI re-renders when updated.

🇬🇧 English Definition

State is an internal data object managed within a component that holds information that may change over time and triggers component re-rendering.

🇮🇳 Hinglish Definition

State component ka personal data hota hai. Jab bhi state update hoti hai, React automatically component ko dobara draw (re-render) karta hai.

Core Concepts & Rules

  • Import useState from 'react': const [state, setState] = useState(initialValue);
  • state holds the current value; setState is the setter function to update it.
  • Never mutate state directly (e.g., state = 5 is forbidden); always use setState(newValue).
  • State updates are asynchronous and batched for optimal performance.

Practical Takeaways & Best Practices

Mastering React State & useState Hook builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - React State & useState Hook 
import React, { useState } from "react";

export default function Counter() {
  const [count, setCount] = useState(0);

  const handleIncrement = () => setCount(count + 1);
  const handleDecrement = () => setCount(count - 1);
  const handleReset = () => setCount(0);

  return (
    <div>
      <h2>Counter Value: {count}</h2>
      <button onClick={handleIncrement}>Increase (+1)</button>
      <button onClick={handleDecrement}>Decrease (-1)</button>
      <button onClick={handleReset}>Reset</button>
    </div>
  );
}
📤 Expected Output / Browser UI Render:
Counter Value: 0 [Click Increase -> Counter Value: 1] [Click Decrease -> Counter Value: 0]

Module 3: Handling Browser Events in React

React uses SyntheticEvents to handle user interactions consistently across all web browsers.

🇬🇧 English Definition

SyntheticEvent is React's cross-browser wrapper around native browser events, ensuring identical event property behavior across all platforms.

🇮🇳 Hinglish Definition

React me events camelCase me likhe jate hai jaise onClick, onChange, onSubmit. Ye browser ke events ko wrap karke uniform behavior dete hai.

Core Concepts & Rules

  • Event handlers are passed as function references without parentheses: onClick={handleClick}.
  • To pass inline parameters, wrap in an arrow function: onClick={() => handleDelete(id)}.
  • Use e.preventDefault() to block default HTML form submissions.
  • e.target.value extracts input field text during onChange events.

Practical Takeaways & Best Practices

Mastering Handling Browser Events in React builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - Handling Browser Events in React 
export default function EventDemo() {
  const handleClick = (message) => {
    alert("Notification: " + message);
  };

  const handleInputChange = (e) => {
    console.log("Current Typing Value:", e.target.value);
  };

  return (
    <div>
      <button onClick={() => handleClick("Hello by Instructor")}>Click Alert</button>
      <input type="text" placeholder="Type here..." onChange={handleInputChange} />
    </div>
  );
}
📤 Expected Output / Browser UI Render:
Alert Popup: Notification: Hello by Instructor Console output: Current Typing Value: [User Typed Text]

Module 4: Functional State Updates & Updating Objects/Arrays

Updating complex state structures safely using callback updates and spread operators.

🇬🇧 English Definition

Functional State Updates pass a callback function to the state updater to ensure updates rely on the latest state snapshot without race conditions.

🇮🇳 Hinglish Definition

Jab state previous state par depend karti ho, tab callback function (prev => prev + 1) use karna safe hota hai. Objects/Arrays ke liye spread operator (...) use kare.

Core Concepts & Rules

  • Prevents stale closure bugs: setCount(prevCount => prevCount + 1).
  • Updating Object State: setUser(prev => ({ ...prev, name: 'Instructor' }));
  • Updating Array State: setItems(prev => [...prev, newItem]);
  • Removing Array Item: setItems(prev => prev.filter(item => item.id !== targetId));

Practical Takeaways & Best Practices

Mastering Functional State Updates & Updating Objects/Arrays builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - Functional State Updates & Updating Objects/Arrays 
import React, { useState } from "react";

export default function UserStateDemo() {
  const [user, setUser] = useState({ name: "Student", score: 80 });

  const updateScore = () => {
    setUser(prevUser => ({
      ...prevUser,
      score: prevUser.score + 10
    }));
  };

  return (
    <div>
      <h3>User: {user.name} | Score: {user.score}</h3>
      <button onClick={updateScore}>Add +10 Score</button>
    </div>
  );
}
📤 Expected Output / Browser UI Render:
User: Student | Score: 80 [Click Button -> User: Student | Score: 90]
