Module 1: Controlled Components Concept & Form Binding

In React, controlled components have their form element values driven by React component state.

🇬🇧 English Definition

A Controlled Component is an input element whose value is controlled by React state, making React the Single Source of Truth for input data.

🇮🇳 Hinglish Definition

Controlled Component wo form input hota hai jiska text/value React state dwara control hoti hai aur onChange event har keystroke par state update karta hai.

Core Concepts & Rules

  • Value attribute is bound to state: value={text}.
  • onChange handler captures keystrokes and updates state: onChange={(e) => setText(e.target.value)}.
  • Single Source of Truth ensures form values are always predictable.
  • Allows instant inline validation, character counters, and button enabling/disabling.

Practical Takeaways & Best Practices

Mastering Controlled Components Concept & Form Binding builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - Controlled Components Concept & Form Binding 
import React, { useState } from "react";

export default function SimpleForm() {
  const [name, setName] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault();
    alert("Submitted Name: " + name);
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>Enter Student Name:</label>
      <input 
        type="text" 
        value={name} 
        onChange={(e) => setName(e.target.value)} 
        placeholder="e.g. Instructor"
      />
      <button type="submit">Submit</button>
      <p>Live Preview: {name}</p>
    </form>
  );
}
📤 Expected Output / Browser UI Render:
Form renders input bound to name state. Typing updates Live Preview instantly.

Module 2: Handling Multiple Form Inputs with a Single State Object

Efficiently managing multi-field forms using computed property names.

🇬🇧 English Definition

Multiple form inputs can be dynamically managed with a single object state by extracting input name and value attributes in the handler.

🇮🇳 Hinglish Definition

Ek hi handler function me multiple inputs ko manage karne ke liye input ka name attribute [e.target.name] computed property key ki tarah use hota hai.

Core Concepts & Rules

  • Set input name attributes to match state object property keys (name='email').
  • Handler formula: setFormData({ ...formData, [e.target.name]: e.target.value }).
  • Supports text fields, textareas, selects, and checkboxes.

Practical Takeaways & Best Practices

Mastering Handling Multiple Form Inputs with a Single State Object builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - Handling Multiple Form Inputs with a Single State Object 
import React, { useState } from "react";

export default function MultiInputForm() {
  const [formData, setFormData] = useState({
    username: "",
    email: "",
    role: "student"
  });

  const handleChange = (e) => {
    const { name, value } = e.target;
    setFormData(prev => ({ ...prev, [name]: value }));
  };

  return (
    <form>
      <input name="username" value={formData.username} onChange={handleChange} placeholder="Username" />
      <input name="email" value={formData.email} onChange={handleChange} placeholder="Email" />
      <select name="role" value={formData.role} onChange={handleChange}>
        <option value="student">Student</option>
        <option value="teacher">Teacher</option>
      </select>
      <pre>{JSON.stringify(formData, null, 2)}</pre>
    </form>
  );
}
📤 Expected Output / Browser UI Render:
Multi-field state updates live into formatted JSON preview object.

Module 3: Form Validation & Error Message Handling

Adding client-side validation logic before processing form submission.

🇬🇧 English Definition

Form validation ensures submitted user data meets required format rules, rendering custom error messages when validation checks fail.

🇮🇳 Hinglish Definition

Form submit hone se pehle data check karke invalid fields ke paas error message dikhana form validation kehllata hai.

Core Concepts & Rules

  • Maintain an errors state object: const [errors, setErrors] = useState({});
  • Validate required fields, string length, or email regex patterns on submit.
  • If errors exist, block submission and display error messages in red.

Practical Takeaways & Best Practices

Mastering Form Validation & Error Message Handling builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - Form Validation & Error Message Handling 
import React, { useState } from "react";

export default function ValidatedForm() {
  const [email, setEmail] = useState("");
  const [error, setError] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault();
    if (!email.includes("@")) {
      setError("Invalid Email Address: Must contain @ symbol!");
    } else {
      setError("");
      alert("Form Valid! Submitting data by Instructor...");
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="text" value={email} onChange={(e) => setEmail(e.target.value)} placeholder="Email" />
      {error && <p style={{ color: "red" }}>{error}</p>}
      <button type="submit">Validate & Submit</button>
    </form>
  );
}
📤 Expected Output / Browser UI Render:
Submitting invalid email -> Shows red error: Invalid Email Address: Must contain @ symbol!
