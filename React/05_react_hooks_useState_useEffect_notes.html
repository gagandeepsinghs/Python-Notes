Module 1: Rules of React Hooks

Strict guidelines mandated by React to guarantee hook call ordering across renders.

🇬🇧 English Definition

React Hooks are special functions that let you hook into React state and lifecycle features from functional components.

🇮🇳 Hinglish Definition

Hooks React functional components me state aur lifecycle features use karne ki permission dete hai. Inhe humesha function ke top level par call karna zaroori hai.

Core Concepts & Rules

  • Rule 1: Only call hooks at the TOP LEVEL of your component. Do NOT call inside loops, conditions, or nested functions.
  • Rule 2: Only call hooks from REACT FUNCTIONAL COMPONENTS or Custom Hooks.
  • Hook names ALWAYS start with the prefix 'use' (e.g., useState, useEffect).

Practical Takeaways & Best Practices

Mastering Rules of React Hooks builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - Rules of React Hooks Created by Gagan Sir 
// CORRECT Usage:
import React, { useState, useEffect } from "react";

export default function HookRulesDemo() {
  // 1. Called at Top Level
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = "Count: " + count;
  }, [count]);

  return <button onClick={() => setCount(count + 1)}>Increment</button>;
}
📤 Expected Output / Browser UI Render:
Updates Browser Tab Document Title dynamically to 'Count: 1'.

Module 2: The useEffect Hook & Lifecycle Management

Performing side effects such as data fetching, timers, DOM manipulation, and subscriptions.

🇬🇧 English Definition

useEffect tells React that your component needs to perform a side effect after rendering or when specific dependency values change.

🇮🇳 Hinglish Definition

useEffect Side Effects (API calls, timers, document title update) handle karne me kaam aata hai. Ye componentDidMount, componentDidUpdate aur componentWillUnmount ko combine karta hai.

Core Concepts & Rules

  • No Dependency Array: Runs after EVERY single render.
  • Empty Dependency Array []: Runs ONLY ONCE when component mounts (Initial render).
  • With Dependencies [dep1, dep2]: Runs on mount AND whenever dep1 or dep2 change.

Practical Takeaways & Best Practices

Mastering The useEffect Hook & Lifecycle Management builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - The useEffect Hook & Lifecycle Management Created by Gagan Sir 
import React, { useState, useEffect } from "react";

export default function EffectDemo() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    // Mount effect
    console.log("Component Mounted into DOM");
  }, []); // Runs once on mount

  return <h2>Elapsed Time: {seconds} seconds</h2>;
}
📤 Expected Output / Browser UI Render:
Console: Component Mounted into DOM (Runs once)

Module 3: Cleanup Functions in useEffect (Preventing Memory Leaks)

Cleaning up timers, event listeners, and subscriptions before unmounting.

🇬🇧 English Definition

The cleanup function returned by useEffect is executed before the component unmounts or before re-running the effect to prevent memory leaks.

🇮🇳 Hinglish Definition

useEffect se ek function return kiya jata hai jo component unmount hote hi chal kar timer stop karta hai ya event listener remove karta hai, jisse memory leak nahi hota.

Core Concepts & Rules

  • Return a cleanup function: return () => { clearInterval(timer); };
  • Executes when component disappears from screen or before effect re-runs.
  • Essential for interval timers, window resize listeners, and WebSocket subscriptions.

Practical Takeaways & Best Practices

Mastering Cleanup Functions in useEffect (Preventing Memory Leaks) builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - Cleanup Functions in useEffect (Preventing Memory Leaks) Created by Gagan Sir 
import React, { useState, useEffect } from "react";

export default function TimerComponent() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    const intervalId = setInterval(() => {
      setSeconds(prev => prev + 1);
    }, 1000);

    // Cleanup function
    return () => {
      clearInterval(intervalId);
      console.log("Timer Cleared! Memory leak avoided.");
    };
  }, []);

  return <h3>Live Timer: {seconds}s</h3>;
}
📤 Expected Output / Browser UI Render:
Live Timer increments every second. Unmounting logs 'Timer Cleared! Memory leak avoided.'

Module 4: Data Fetching with useEffect & API Calls

Fetching external asynchronous data when a component mounts.

🇬🇧 English Definition

useEffect is the primary location for executing asynchronous HTTP fetch calls and updating state with fetched network payloads.

🇮🇳 Hinglish Definition

Web API se data mangwane ke liye useEffect ke andar fetch() call karke responses ko state me set kiya jata hai.

Core Concepts & Rules

  • Do NOT mark the main useEffect callback as async; define an internal async function.
  • Manage loading state: const [loading, setLoading] = useState(true);
  • Manage error state: const [error, setError] = useState(null);

Practical Takeaways & Best Practices

Mastering Data Fetching with useEffect & API Calls builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - Data Fetching with useEffect & API Calls Created by Gagan Sir 
import React, { useState, useEffect } from "react";

export default function FetchPosts() {
  const [posts, setPosts] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    async function loadData() {
      try {
        // Simulated API Response
        const mockData = [
          { id: 1, title: "React Basics by Gagan Sir" },
          { id: 2, title: "Hooks Deep Dive" }
        ];
        setPosts(mockData);
      } finally {
        setLoading(false);
      }
    }
    loadData();
  }, []);

  if (loading) return <p>Loading API Data...</p>;
  return (
    <ul>
      {posts.map(p => <li key={p.id}>{p.title}</li>)}
    </ul>
  );
}
📤 Expected Output / Browser UI Render:
Renders list of fetched posts cleanly after loading state resolves.
