Module 1: The useRef Hook (DOM Access & Mutable Values)

Accessing imperative DOM nodes directly and persisting mutable values across renders without causing re-renders.

🇬🇧 English Definition

useRef returns a mutable ref object whose .current property is initialized to the passed argument and persists across component re-renders.

🇮🇳 Hinglish Definition

useRef do kaam karta hai: 1. DOM element ko directly focus/access karna. 2. Aisi value save karna jiske change hone par UI re-render NA HO.

Core Concepts & Rules

  • Attaching ref to element: .
  • Accessing element: inputRef.current.focus().
  • Modifying .current does NOT trigger component re-render.

Practical Takeaways & Best Practices

Mastering The useRef Hook (DOM Access & Mutable Values) builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - The useRef Hook (DOM Access & Mutable Values) 
import React, { useRef } from "react";

export default function FocusInput() {
  const inputEl = useRef(null);
  const renderCount = useRef(0);

  renderCount.current++;

  const handleFocus = () => {
    inputEl.current.focus();
    inputEl.current.style.border = "2px solid orange";
  };

  return (
    <div>
      <input ref={inputEl} type="text" placeholder="Click button to focus" />
      <button onClick={handleFocus}>Focus Input</button>
      <p>Component Render Count: {renderCount.current}</p>
    </div>
  );
}
📤 Expected Output / Browser UI Render:
Clicking button focuses input field and highlights border with orange outline without re-render cycle.

Module 2: The useReducer Hook (Complex State Logic Management)

An alternative to useState for managing complex state transitions and actions.

🇬🇧 English Definition

useReducer is a hook used for managing complex component state transitions using a Reducer function and Dispatch actions, similar to Redux.

🇮🇳 Hinglish Definition

useReducer tab use karte hai jab state logic complex ho (jaise Multiple sub-values or next state depends on previous state). Command dispatch({ type: 'ACTION' }) se chalta hai.

Core Concepts & Rules

  • Syntax: const [state, dispatch] = useReducer(reducer, initialState);
  • Reducer function: (state, action) => newState.
  • Dispatch triggers state updates: dispatch({ type: 'INCREMENT', payload: 5 }).

Practical Takeaways & Best Practices

Mastering The useReducer Hook (Complex State Logic Management) builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - The useReducer Hook (Complex State Logic Management) 
import React, { useReducer } from "react";

const initialState = { count: 0 };

function counterReducer(state, action) {
  switch (action.type) {
    case "INCREMENT":
      return { count: state.count + 1 };
    case "DECREMENT":
      return { count: state.count - 1 };
    case "RESET":
      return { count: 0 };
    default:
      return state;
  }
}

export default function ReducerDemo() {
  const [state, dispatch] = useReducer(counterReducer, initialState);

  return (
    <div>
      <h3>Reducer Count: {state.count}</h3>
      <button onClick={() => dispatch({ type: "INCREMENT" })}>+1</button>
      <button onClick={() => dispatch({ type: "DECREMENT" })}>-1</button>
      <button onClick={() => dispatch({ type: "RESET" })}>Reset</button>
    </div>
  );
}
📤 Expected Output / Browser UI Render:
Reducer State updates cleanly via dispatched action types.

Module 3: The useMemo Hook (Caching Expensive Calculations)

Memoizing heavy computation results to prevent re-running on un-related renders.

🇬🇧 English Definition

useMemo returns a memoized value that only recalculates when one of its specified dependencies changes, optimizing application rendering speed.

🇮🇳 Hinglish Definition

useMemo kisi heavy calculation ke result ko memory me cache kar leta hai. Jab tak uski dependencies change na ho, tab tak repeat calculation nahi hoti.

Core Concepts & Rules

  • Syntax: const memoizedResult = useMemo(() => computeHeavyTask(data), [data]);
  • Use only for genuinely expensive operations (e.g., sorting 10,000 items).
  • Do NOT over-use useMemo for trivial calculations as it adds memory overhead.

Practical Takeaways & Best Practices

Mastering The useMemo Hook (Caching Expensive Calculations) builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - The useMemo Hook (Caching Expensive Calculations) 
import React, { useState, useMemo } from "react";

export default function MemoDemo() {
  const [number, setNumber] = useState(5);
  const [dark, setDark] = useState(false);

  // Expensive Factorial Calculation
  const factorial = useMemo(() => {
    console.log("Calculating Factorial...");
    let res = 1;
    for (let i = 1; i <= number; i++) res *= i;
    return res;
  }, [number]);

  return (
    <div>
      <h3>Factorial of {number} = {factorial}</h3>
      <button onClick={() => setNumber(number + 1)}>Increment Number</button>
      <button onClick={() => setDark(!dark)}>Toggle Theme (No Recalculation)</button>
    </div>
  );
}
📤 Expected Output / Browser UI Render:
Toggling theme re-renders UI instantly WITHOUT recalculating factorial!

Module 4: The useCallback Hook (Caching Function References)

Memoizing callback functions to prevent re-creating function instances across renders.

🇬🇧 English Definition

useCallback returns a memoized version of a callback function that only changes if one of the dependencies has changed, preventing un-necessary child re-renders.

🇮🇳 Hinglish Definition

useCallback ek function reference ko cache karta hai taaki parent component re-render hone par child component ko wahi purana function reference mile aur child re-render hone se bach jaye.

Core Concepts & Rules

  • Syntax: const memoizedCallback = useCallback(() => { doSomething(a, b); }, [a, b]);
  • Complements React.memo() on child components.

Practical Takeaways & Best Practices

Mastering The useCallback Hook (Caching Function References) builds clean, modular React application logic. Study code examples and definitions carefully.

💻 Practical Code Example - The useCallback Hook (Caching Function References) 
import React, { useState, useCallback } from "react";

export default function CallbackDemo() {
  const [count, setCount] = useState(0);

  const handleClick = useCallback(() => {
    console.log("Button Clicked with count:", count);
  }, [count]);

  return (
    <div>
      <h2>Count: {count}</h2>
      <button onClick={() => setCount(count + 1)}>Add Count</button>
    </div>
  );
}
📤 Expected Output / Browser UI Render:
Function instance cached until count dependency changes.
