2. Master Python Dockerfile & Cache Strategy

Hinglish: Stable files (jaise requirements.txt) ko pehle copy karo aur install karo. Source code (jo baar-baar change hota hai) baad me copy karo taaki Docker build cache use kar sake.
# syntax=docker/dockerfile:1
FROM python:3.12-slim

WORKDIR /app

# Copy requirements FIRST to use layer caching
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy the rest of the code later
COPY . .

ENV PYTHONUNBUFFERED=1
EXPOSE 8000

CMD ["python", "app.py"]

3. Multi-Stage Builds

Use multiple FROM stages so build tools stay in the build stage and only required runtime artifacts enter the final image. This drastically reduces image size and attack surface.

FROM node:22 AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# Second stage: only the runtime
FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
