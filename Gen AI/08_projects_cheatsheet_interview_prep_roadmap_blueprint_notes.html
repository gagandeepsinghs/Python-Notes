51. Practical Python Recipes

🇬🇧 English Definition
Reusable, battle-tested Python code recipes for simple text generation, basic RAG pipelines, tool calling execution, FastAPI skeletons, and secure environment variable handling.
🇮🇳 Hinglish Definition
Everyday use hone wale practical Python code recipes jo RAG, LLM API calls, Tool Execution aur FastAPI backend setup ke liye reusable templates hain.
// Production Python Recipe: Safe API Call with Retry Logic import time def call_llm_with_retry(prompt_func, max_retries=3): for attempt in range(1, max_retries + 1): try: return prompt_func() except Exception as e: print(f"Attempt {attempt} failed: {e}") time.sleep(2 ** attempt) // Exponential backoff raise RuntimeError("LLM API call failed after max retries.") // Test run simulation print(call_llm_with_retry(lambda: "API Success!"))
🔍 Line-by-Line Code Breakdown
  • exponential backoff (2 ** attempt): Prevents overwhelming downstream APIs during transient network glitches or rate limits.
🎯 Interview Focus & Questions

Q: Why is exponential backoff essential in production API integrations?
A: It handles rate limits (HTTP 429) gracefully and gives remote servers time to recover without creating a thundering herd problem.

59. Debugging Framework

🇬🇧 English Definition
Step-by-step diagnostic workflow: Reproduce issue -> Inspect logs/prompts/context -> Isolate component (model vs retrieval vs app vs data) -> Fix root cause -> Validate on benchmark test set -> Monitor in production.
🇮🇳 Hinglish Definition
Debugging Framework: Impact → Reproduce → Inspect logs/prompts/retrieved context → Isolate component (Model vs Retrieval vs Data) → Fix root cause → Validate on test set → Monitor in production.
// Automated Diagnostic Isolation Pseudocode def isolate_genai_bug(retrieved_chunks, model_output, ground_truth): if not retrieved_chunks: return "BUG LOCATION: Retrieval Layer (No context found)" elif ground_truth not in " ".join(retrieved_chunks): return "BUG LOCATION: Chunking/Indexing Layer (Wrong context retrieved)" elif model_output != ground_truth: return "BUG LOCATION: Generation Layer (Model ignored context / Hallucinated)" return "NO BUG DETECTED: Output matches ground truth." print(isolate_genai_bug(["RAG is retrieval..."], "Wrong answer", "RAG is retrieval..."))
🔍 Line-by-Line Code Breakdown
  • isolate_genai_bug: Isolates whether a failure stems from Retrieval, Chunking, or Model Generation layers.
🎯 Interview Focus & Questions

Q: How do you isolate whether a bug is caused by the embedding model or the LLM?
A: Inspect the retrieved text chunks independently of the LLM. If the retrieved chunks contain the answer, the LLM prompt/decoding is at fault. If missing, the retriever/embedding model is at fault.
