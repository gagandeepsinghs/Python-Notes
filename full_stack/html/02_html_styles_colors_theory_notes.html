Module 1: Text Formatting Elements Theory

Tags providing semantic meaning and visual styling to text.

Core Theory & Principles

  • <b> vs <strong>: <b> is purely visual bold; <strong> adds semantic importance for screen readers.
  • <i> vs <em>: <i> is visual italic; <em> adds semantic emphasis.
  • <mark>: Highlighted text.
  • <del> and <ins>: Strikethrough deleted text and underlined inserted text.
  • <sub> and <sup>: Subscript (H2O) and Superscript (E=mc2).

Practical Key Takeaways

Mastering Text Formatting Elements Theory builds fundamental development capability. Review practical code and outputs carefully.

<p>Original price: <del>$99</del> <mark>Special Offer: $49</mark></p>

Module 2: HTML Quotations & Color Models Theory

Block quotes, citations, abbreviations, and color representation.

Core Theory & Principles

  • <blockquote>: Indented block quotation with cite attribute.
  • <q>: Short inline quote surrounded by quotation marks.
  • <abbr>: Abbreviation with title tooltip.
  • RGB Color Model: rgb(red, green, blue) where values range 0-255.
  • RGBA Color Model: rgba(red, green, blue, alpha) where alpha ranges 0.0 (transparent) to 1.0 (opaque).

Practical Key Takeaways

Mastering HTML Quotations & Color Models Theory builds fundamental development capability. Review practical code and outputs carefully.
