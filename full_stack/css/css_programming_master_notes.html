Module 1: Chapter 1: CSS Introduction & Setup

CSS is the language we use to style an HTML document. CSS describes how HTML elements should be displayed.

Core Theory & Principles

  • CSS stands for Cascading Style Sheets.
  • CSS saves a lot of work. It can control the layout of multiple web pages all at once.
  • External stylesheets are stored in CSS files (.css).

Practical Key Takeaways

Mastering Chapter 1: CSS Introduction & Setup builds fundamental development capability. Review practical code and outputs carefully.

💻 Practical Code Example - Chapter 1: CSS Introduction & Setup 
<!DOCTYPE html>
<html>
<head>
<style>
  body {
    background-color: rgb(15, 23, 42);
    color: rgb(241, 245, 249);
    font-family: sans-serif;
  }
  h1 {
    color: rgb(56, 189, 248);
    text-align: center;
  }
</style>
</head>
<body>
  <h1>Welcome to CSS Learning with Instructor</h1>
  <p>CSS controls colors, fonts, layouts, and animations.</p>
</body>
</html>

Module 2: Chapter 2: CSS Syntax & Rulesets

A CSS rule-set consists of a selector and a declaration block.

Core Theory & Principles

  • The selector points to the HTML element you want to style.
  • The declaration block contains one or more declarations separated by semicolons.
  • Each declaration includes a CSS property name and a value, separated by a colon.

Practical Key Takeaways

Mastering Chapter 2: CSS Syntax & Rulesets builds fundamental development capability. Review practical code and outputs carefully.

💻 Practical Code Example - Chapter 2: CSS Syntax & Rulesets 
p {
  color: rgb(74, 222, 128);
  font-size: 18px;
  line-height: 1.6;
}

Module 3: Chapter 3: CSS Selectors (Element, Class, ID & Grouping)

CSS selectors are used to 'find' (or select) the HTML elements you want to style.

Core Theory & Principles

  • Element Selector: Selects HTML elements based on tag name (p, h1, div).
  • Class Selector: Selects elements with a specific class attribute (.highlight).
  • ID Selector: Selects a single element with a specific id attribute ([id="main"]).
  • Universal Selector (*): Selects all HTML elements on the page.
  • Grouping Selector: Selects all elements with the same style definitions (h1, h2, p).

Practical Key Takeaways

Mastering Chapter 3: CSS Selectors (Element, Class, ID & Grouping) builds fundamental development capability. Review practical code and outputs carefully.

💻 Practical Code Example - Chapter 3: CSS Selectors (Element, Class, ID & Grouping) 
<!DOCTYPE html>
<html>
<head>
<style>
  /* Grouping Selector */
  h1, h2, p {
    text-align: center;
  }
  /* Class Selector */
  .card {
    background: rgb(30, 41, 59);
    color: white;
    padding: 15px;
    border-radius: 8px;
  }
</style>
</head>
<body>
  <div class="card">
    <h2>CSS Selectors Overview</h2>
    <p>Styled with grouped and class selectors.</p>
  </div>
</body>
</html>
