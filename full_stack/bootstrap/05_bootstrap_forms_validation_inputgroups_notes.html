Module 1: Form Controls, Selects, Checks & Radios

Styling native HTML inputs, selects, checkboxes, and radio buttons consistently.

🇬🇧 English Definition

Bootstrap form classes (form-control, form-select, form-check-input) apply consistent padding, borders, focus outlines, and full-width layout styling to form controls.

🇮🇳 Hinglish Definition

form-control input fields ko style karta hai. form-select dropdown select ko aur form-check checkboxes ko modern look deta hai.

Core Concepts & Rules

  • form-control: Styles text inputs, textareas, and file inputs.
  • form-select: Styles dropdown select elements.
  • form-check: Wraps checkbox/radio input and label (

🎯 Interview Focus & Questions

  • Q: What is form-control?
    A: A Bootstrap class that applies full-width layout, rounded borders, padding, and focus ring styling to form inputs.
💻 Practical Bootstrap Code Example - Form Controls, Selects, Checks & Radios Created by Gagan Sir 
<form>
  <div class="mb-3">
    <label for="email" class="form-label">Email Address</label>
    <input type="email" class="form-control" id="email" placeholder="name@example.com">
  </div>
  <div class="form-check mb-3">
    <input class="form-check-input" type="checkbox" id="terms">
    <label class="form-check-label" for="terms">Accept Terms</label>
  </div>
  <button type="submit" class="btn btn-primary">Submit</button>
</form>
📤 Expected Rendered Result:
Clean form layout with styled text input, custom checkbox, and primary submit button.
