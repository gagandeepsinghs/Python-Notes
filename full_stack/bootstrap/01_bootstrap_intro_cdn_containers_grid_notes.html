Module 2: Containers, Breakpoints & 12-Column Grid System

Building mobile-first layouts using containers, rows, and responsive column grids.

🇬🇧 English Definition

Bootstrap's grid is a responsive 12-column layout system based on containers, rows, and breakpoint columns (sm, md, lg, xl, xxl).

🇮🇳 Hinglish Definition

Grid formula hai: container -> row -> columns. 12 parts me width divide karke responsive layout bana sakte ho.

Core Concepts & Rules

  • .container: Fixed-width responsive container that centers content.
  • .container-fluid: Full-width container spanning 100% of viewport width.
  • 12-Column Grid: col-md-4 takes 4 units (1/3 width); col-md-8 takes 8 units (2/3 width).

🎯 Interview Focus & Questions

  • Q: container vs container-fluid?
    A: container has responsive max-widths; container-fluid spans 100% width across all viewports.
  • Q: What is a gutter?
    A: Gutters are the horizontal and vertical padding between grid columns controlled via g-, gx-, gy- classes.
