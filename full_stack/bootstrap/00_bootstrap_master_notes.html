Chapter 1: Introduction to Bootstrap

🇬🇧 English Definition

Bootstrap is a popular front-end CSS framework providing responsive layout tools, CSS utilities, and ready-made UI components.

🇮🇳 Hinglish Definition

Bootstrap ready-made CSS classes aur components deta hai. Isse button, navbar, cards, grid, forms aur responsive layouts jaldi se bana sakte ho.

💻 First Bootstrap Button Created by Gagan Sir 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<button class="btn btn-primary">Click Me</button>
📤 Rendered Result:
Blue primary styled button with rounded corners.

Chapter 5: Grid System

🇬🇧 English Definition

Bootstrap's grid is a responsive layout system based on containers, rows, and 12-column breakpoint units.

🇮🇳 Hinglish Definition

Grid ko simple formula samjho: container -> row -> columns. 12 parts me width divide karke layout control kar sakte ho.

💻 12-Column Responsive Grid Created by Gagan Sir 
<div class="container">
  <div class="row g-3">
    <div class="col-12 col-md-4"><div class="p-3 border">Sidebar</div></div>
    <div class="col-12 col-md-8"><div class="p-3 border">Content</div></div>
  </div>
</div>
📤 Rendered Result:
1/3 Sidebar + 2/3 Content layout on desktop, stacked on mobile.

Chapter 20: Responsive Navbar

🇬🇧 English Definition

A navbar is a responsive navigation header for branding, links, and actions collapsing automatically on mobile viewports.

🇮🇳 Hinglish Definition

Navbar responsive navigation component hai jo mobile par collapse ho jata hai.

💻 Navbar Component Created by Gagan Sir 
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container">
    <a class="navbar-brand" href="javascript:void(0)">MySite</a>
    <button class="navbar-toggler" data-bs-toggle="collapse" data-bs-target="navDemo">
      <span class="navbar-toggler-icon"></span>
    </button>
  </div>
</nav>
📤 Rendered Result:
Dark responsive navbar with brand name and collapsible toggler icon.
