1. What is a String in Python & How to Define It?

Easy English

A string in Python is used to store textual data. It is a sequence/collection of characters enclosed within single quotes (' '), double quotes (" "), or triple quotes (''' ''' / """ """).

Hinglish

String Python mein text/data ko store karne ke liye use hoti hai. String characters ka collection hoti hai aur ise single, double ya triple quotes mein likha jata hai.

Syntax: string_variable = "text"
Python Code - Definition
name = "Gagandeep"
print(name)
Output
Gagandeep

2. How to Create Strings in Python?

Easy English

Strings are created using quotes. Single quotes for short words, double quotes for standard text, and triple quotes for multi-line strings.

Hinglish

Python mein string create karne ke liye single, double ya triple quotes ka use kiya jata hai.

Syntax: variable = "string"
Python Code - Creating Strings
name = "Gagan"
city = 'Chandigarh'
message = "Welcome to Python"
print(name)
print(city)
print(message)
Output
Gagan
Chandigarh
Welcome to Python

3. What is String Indexing & How to Access Characters?

Easy English

String indexing allows accessing individual characters. In Python, indexing starts at 0 for the first character.

Hinglish

String indexing ka use string ke individual characters ko access karne ke liye hota hai. Python mein indexing 0 se start hoti hai.

Syntax: string[index]
Python Code - Indexing
name = "Python"
print(name[0])
print(name[1])
print(name[2])
Output
P
y
t

4. What is Positive & Negative Indexing in Python?

Easy English

Positive indexing goes left-to-right starting at 0. Negative indexing goes right-to-left starting at -1 for the last character.

Hinglish

Positive indexing left se right jaati hai (0 se start). Negative indexing right se left jaati hai (-1 se start).

Syntax: string[positive_index] | string[negative_index]
Python Code - Positive & Negative Indexing
name = "Python"
print(name[0])
print(name[5])
print(name[-1])
print(name[-2])
Output
P
n
n
o

5. What is String Slicing & Step Slicing?

Easy English

String slicing extracts a portion of a string using start, end, and optional step indices: string[start:end:step].

Hinglish

String slicing ka use string ke ek specific portion ko extract karne ke liye hota hai. step=2 ka matlab 1 step chhod kar agla character aayega.

Syntax: string[start:end] | string[start:end:step]
Python Code - Slicing
name = "Python"
print(name[0:3])
print(name[2:6])
print(name[:4])
print(name[2:])
print(name[::2])
Output
Pyt
thon
Pyth
thon
Pto

6. What is String Immutability & How to Change a String?

Easy English

Strings are immutable, meaning individual characters cannot be changed directly in-place. To modify a string, you create a new one using concatenation.

Hinglish

Strings immutable hoti hain, matlab unke individual characters ko directly modify nahi kar sakte. Nayi string bana kar change karte hain.

Python Code - Immutability
name = "Python"
name = "J" + name[4:]
print(name)
Output
Jon

15. How to Format Strings Using f-Strings?

Easy English

f-Strings allow embedding expressions directly inside string literals using curly braces {variable}.

Hinglish
