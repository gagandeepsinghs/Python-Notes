Chapter 1

What is a Loop

A loop is a programming structure that is used to repeat a block of code multiple times until a specific condition is met.

Loops eliminate code duplication by automating repetitive iterations across ranges, sequences, or condition-driven tasks.

Key Purpose

Instead of manually repeating print or calculation statements, loops allow executing instructions N times cleanly.

Chapter 2

The for Loop

The for loop is used to repeat a block of code a fixed number of times or to iterate over a sequence like a list, string, or range.

For loop tab use hota hai jab hume koi kaam fixed number of times repeat karna ho ya kisi list, string ya range ke elements ko ek-ek karke access karna ho.

Example 1: Iterating over range()

range(1, 10) generates numbers from 1 to 9 (upper bound non-inclusive).

Chapter 3

The while Loop

A while loop repeats a block of code as long as the condition remains true.

While loop tab tak chalta hai jab tak condition true rehti hai. It evaluates conditions before executing the body (Entry-controlled loop).

Chapter 4

Nested Loops

A nested loop is a loop inside another loop. Jab ek loop ke andar doosra loop use hota hai to use nested loop kehte hain.

The inner loop completes all its iterations for every single step of the outer loop.

Chapter 5

Do-While Loop Simulation

A do-while loop is a loop that executes the code block at least once and then checks the condition.

Do-while loop me pehle code run hota hai aur baad me condition check hoti hai, isliye loop kam se kam ek baar zaroor run hota hai.

Python Implementation

Python does not have a native do-while keyword. We simulate exit-controlled loops using an infinite while True: loop with an internal if condition: break statement.

Chapter 6

Break & Continue Statements

Loop control statements alter normal execution flow:

1. break Statement

The break statement is used to immediately terminate the loop. Break statement loop ko turant stop kar deta hai.

2. continue Statement

The continue statement skips the current iteration and moves to the next iteration of the loop. Continue statement current step ko skip kar deta hai aur loop next iteration pe chala jata hai.
