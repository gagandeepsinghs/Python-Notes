Chapter 1

What is Type Casting

Type Casting ka matlab hai ek data type ko doosre data type mein convert karna. Python programming me calculations aur user inputs handling ke liye different data types me values transform ki jaati hain.

Common Type Casting Functions

  • int() — Converts value to Integer
  • float() — Converts value to Floating-point number
  • str() — Converts value to String
  • bool() — Converts value to Boolean (True/False)
  • list() — Converts iterable to List
  • tuple() — Converts iterable to Tuple
  • set() — Converts iterable to Set

Chapter 6

Collection Casting: list(), tuple(), set()

Iterables (strings, tuples, sets, lists) ko doosre collection types me convert karne ke functions:

1. list() Function

list() kisi iterable ko List mein convert karta hai. List square brackets [] use karti hai, multiple values store karti hai aur mutable hoti hai.

2. tuple() Function

tuple() kisi iterable ko Tuple mein convert karta hai. Tuple round brackets () use karta hai, ordered aur immutable hota hai.

3. set() Function

set() kisi iterable ko Set mein convert karta hai. Set duplicate values ko automatically remove kar deta hai.
