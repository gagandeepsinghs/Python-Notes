Chapter 1

What are Data Types

Data Types in Python are used to define the type of data stored in a variable. They tell Python what kind of value a variable contains, such as a number, text, list, dictionary, or boolean value.

Variables store different kinds of data, and operations on variables depend on their assigned data type.

Key Concept

Python is dynamically typed. You do not need to explicitly declare a variable's data type; Python detects it automatically when a value is assigned.

Chapter 2

Primary Data Types Categories

Python offers several built-in data types grouped into primary categories:

1. Numeric Types

  • int: Integer numbers (e.g. 10, -848561456).
  • float: Decimal numbers (e.g. 9.5, 75.6).
  • complex: Numbers with real and imaginary parts (e.g. 5j, 3 + 4j, or created via complex(3, 4)).

2. Boolean Type

  • bool: Represents boolean truth values: True or False.

Important Distinction

Immutable objects like Strings or Tuples cannot be modified in-place. Modifying a string variable rebinds the variable to a newly created object in memory.

Chapter 5

Sequences, Maps & Sets

Python provides specialized collection data types to manage multiple elements:

Sequence Data Types

  • str: String of characters, e.g. "Hello".
  • list: Ordered mutable collection, e.g. [1, 2, 3, "sumit"].
  • tuple: Ordered immutable collection, e.g. (1, 2, 3).

Mapping Data Type

  • dict: Key-value pairs dictionary, e.g. {"name": "John", "age": 25} (where "name" is key, "John" is value).

Set Data Type

  • set: Unordered collection of unique items, e.g. {2, 5, 9, 9, 9, 7}.
Set Automatic Duplicate Removal

Notice how {2, 5, 9, 9, 9, 7} automatically removes duplicate elements when created, resulting in {2, 5, 7, 9}.
