1. What is a Tuple in Python?

English Definition

A Tuple is an ordered, immutable collection in Python enclosed in round parentheses (). Tuples allow duplicate elements, support indexing/slicing, and cannot be altered after creation.

Hinglish Explanation

Tuple Python mein ek data structure hai jisme multiple values ek hi variable me store hoti hain. Key rule: Tuple change nahi ho sakta (immutable).

  • Ordered: Maintains exact insertion order of items.
  • Immutable: Elements cannot be modified, added, or removed in-place.
  • Allows Duplicates: Can hold identical values multiple times.
  • Heterogeneous Data: Can mix integers, floats, strings, booleans, and lists.

2. Creating Tuples & Syntax Variations

Single Element Comma Rule

Writing num = (10) creates an int integer! To create a single-element tuple, you must include a trailing comma: num = (10,).

Tuple Without Parentheses

Python mein bina round brackets ke bhi numbers separated by commas dene se automatically tuple ban jata hai (Tuple Packing): nums = 10, 20, 30.

Python Code - Creating Tuples
numbers = (10, 20, 30, 40)
empty_tuple = ()
single_elem = (10,)
no_brackets = 10, 20, 30, 40
mixed_data = (10, "Python", 20.5, True)

print("Standard Tuple:", numbers)
print("Single Element Type:", type(single_elem))
print("Without Brackets:", no_brackets)
print("Mixed Tuple:", mixed_data)
Output
Standard Tuple: (10, 20, 30, 40)
Single Element Type: <class 'tuple'>
Without Brackets: (10, 20, 30, 40)
Mixed Tuple: (10, 'Python', 20.5, True)

3. Tuple Indexing & Slicing

Access tuple elements using zero-based indexing tuple[0], negative indexing tuple[-1], or extract sub-tuples using slicing tuple[start:stop:step].

Python Code - Indexing & Slicing
numbers = (10, 20, 30, 40, 50)

print("First element (0):", numbers[0])
print("Last element (-1):", numbers[-1])
print("Slice [1:4]:", numbers[1:4])
print("Step 2 [::2]:", numbers[::2])
print("Reversed [::-1]:", numbers[::-1])
Output
First element (0): 10
Last element (-1): 50
Slice [1:4]: (20, 30, 40)
Step 2 [::2]: (10, 30, 50)
Reversed [::-1]: (50, 40, 30, 20, 10)

4. The Immutability Rule

Attempting to assign a new value to an existing index in a tuple will raise a TypeError.

Python Code - Demonstrating Immutability
numbers = (10, 20, 30)
try:
    numbers[1] = 50
except TypeError as e:
    print("Error caught:", e)
Output
Error caught: 'tuple' object does not support item assignment

6. Tuple Built-in Methods (count & index)

Because tuples are immutable, they only possess two built-in methods: count() and index().

Python Code - count() and index()
numbers = (10, 20, 20, 30, 20, 40)

print("Count of 20:", numbers.count(20))
print("Index of 30:", numbers.index(30))
Output
Count of 20: 3
Index of 30: 3

8. Tuple Packing & Advanced Unpacking (* Operator)

Wildcard * Unpacking

Using *var during unpacking collects excess items into a list: a, b, *c = (10, 20, 30, 40, 50).

Hinglish Explanation

Tuple unpacking se tuple ke values ko multiple variables mein ek sath assign kar sakte hain. * operator bachi hui values ko list ke roop mein store kar leta hai.

Python Code - Unpacking Variations
numbers = (10, 20, 30, 40, 50)

a, b, *c = numbers
print("a:", a, "| b:", b, "| c:", c)

first, *middle, last = numbers
print("first:", first, "| middle:", middle, "| last:", last)
Output
a: 10 | b: 20 | c: [30, 40, 50]
first: 10 | middle: [20, 30, 40] | last: 50

10. Built-in Math & Boolean Functions

Functions like sum(), min(), max(), any(), all(), and sorted() work seamlessly with tuples. Note that sorted() returns a sorted List.

Python Code - Math & Sorting
nums = (50, 20, 40, 10, 30)

print("Sum:", sum(nums))
print("Max:", max(nums))
print("Min:", min(nums))
print("Sorted (returns list):", sorted(nums))
print("Sorted Descending:", sorted(nums, reverse=True))
print("Any True (0, 0, 10):", any((0, 0, 10)))
print("All True (10, 20, 30):", all((10, 20, 30)))
Output
Sum: 150
Max: 50
Min: 10
Sorted (returns list): [10, 20, 30, 40, 50]
Sorted Descending: [50, 40, 30, 20, 10]
Any True (0, 0, 10): True
All True (10, 20, 30): True

12. Advanced Interoperability & Function Returns

Mutable List inside Immutable Tuple

If a tuple contains a list element ([10, 20], [30, 40]), the list itself can be modified in-place data[0][0] = 100 because list objects are mutable.

Tuple as Dictionary Key

Tuples immutable hone ki wajah se hashable hote hain, isliye inko dictionary keys ke roop mein use kiya ja sakta hai: {(101, "Python"): "Gagan"}.

Python Code - Functions Returning Multiple Values
def get_user_info():
    name = "Gagan"
    age = 22
    course = "MCA"
    return name, age, course

result = get_user_info()
print("Function Returned Tuple:", result)

student_dict = {
    (101, "Python"): "Gagan",
    (102, "SQL"): "Rahul"
}
print("Tuple as Dict Key:", student_dict)
Output
Function Returned Tuple: ('Gagan', 22, 'MCA')
Tuple as Dict Key: {(101, 'Python'): 'Gagan', (102, 'SQL'): 'Rahul'}
