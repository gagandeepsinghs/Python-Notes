Chapter 1

Overview & Precedence

Operators are special symbols used to perform operations on values and variables. Python categorizes operators into 7 distinct groups:

OrderCategoryPrimary Use / Function
1ArithmeticPerform mathematical calculations
2AssignmentAssign or update variable values
3ComparisonRelational checks returning True/False
4LogicalCombine multiple conditional expressions
5MembershipTest if a value exists inside a collection
6IdentityCheck if two variables reference the same memory object
7BitwisePerform bit-level operations on integers

Chapter 5

Logical Operators

Logical operators combine conditional statements:

  • and: Returns True if both conditions are True.
  • or: Returns True if at least one condition is True.
  • not: Reverse the boolean result (True becomes False, False becomes True).
Chapter 6

Identity Operators & == vs is

Identity operators check whether two variables refer to the exact same object in computer memory space.

  • is — Returns True if both variables point to the same object.
  • is not — Returns True if variables point to different objects.
Crucial Distinction: == vs is

== compares values (content equality).
is compares object identity (memory reference location).

Chapter 7

Membership Operators

Membership operators check whether a value exists inside a sequence or collection (such as strings, lists, tuples, or sets).

  • in — Returns True if value is present in collection.
  • not in — Returns True if value is NOT present in collection.
