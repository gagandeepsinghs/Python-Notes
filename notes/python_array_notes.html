1 What is NumPy?
NumPy (Numerical Python) is a fundamental Python library used for scientific computing, numerical calculations, and working with multi-dimensional arrays. NumPy arrays are significantly faster, memory-efficient, and optimized compared to standard Python lists.

Python List

Stores pointers to objects scattered in memory. Slower execution.

NumPy ndarray

Continuous contiguous memory blocks (C-style). Ultra-fast SIMD operations.

PYTHON • VERSION CHECK 
import numpy as np

/* Check installed NumPy version */
print("NumPy Version:", np.__version__)
Expected Output
NumPy Version: 1.26.4
2 Creating an Array
Definition: np.array() function is used to create a NumPy array from a Python list or tuple.
Important Note: NumPy arrays hold homogeneous data (elements of the same data type). If you pass mixed data types (like numbers and strings), NumPy automatically upcasts/type-casts everything to a common string type!
PYTHON • ARRAY CREATION 
import numpy as np

/* Mixed data type causes string upcasting */
arr = np.array([10, 20, 30, 40, 50, "gagan"])

print("Array:")
print(arr)
print("Data Type:", arr.dtype)
Expected Output
Array:
['10' '20' '30' '40' '50' 'gagan']
Data Type: <U11

6 Array Properties
Definition: NumPy attributes provide meta-information about the structure, memory, and data format of an array.
  • ndim: Number of dimensions (axes).
  • shape: Tuple representing the dimensions of array (e.g. (2, 3)).
  • size: Total number of elements in the array.
  • dtype: Data type of elements (int64, float64, etc.).
PYTHON • ARRAY ATTRIBUTES 
import numpy as np

arr = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

print("ndim:", arr.ndim)
print("shape:", arr.shape)
print("size:", arr.size)
print("dtype:", arr.dtype)
Expected Output
ndim: 2
shape: (2, 3)
size: 6
dtype: int32 (or int64 depending on OS)
7 Array Indexing (1D & 2D)
Definition: Indexing is used to access a specific element from an array using zero-based indices.
Syntax for 2D: array[row_index, column_index]
PYTHON • INDEXING EXAMPLES 
import numpy as np

/* 1D Indexing */
arr_1d = np.array([10, 20, 30, 40, 60])
print("First element:", arr_1d[0])
print("Last element (Negative):", arr_1d[-1])

/* 2D Indexing */
arr_2d = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

print("Row 0, Col 0:", arr_2d[0, 0])
print("Row 1, Col 2:", arr_2d[1, 2])
Expected Output
First element: 10
Last element (Negative): 60
Row 0, Col 0: 10
Row 1, Col 2: 60
8 Array Slicing (1D & 2D)
Definition: Slicing extracts a range of elements from an array.
Syntax: array[start : stop : step]
2D Syntax: array[row_start:row_stop, col_start:col_stop]
PYTHON • SLICING DEMO 
import numpy as np

arr = np.array([10, 20, 30, 40, 50])
print("Step Slicing (every 2nd):", arr[0:5:2])
print("Reversed Array:", arr[::-1])

/* 2D Matrix Slicing */
arr_2d = np.array([
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
])

/* Extract submatrix: Rows 0 to 1, Cols 1 to 2 */
print("2D Sliced Submatrix:")
print(arr_2d[0:2, 1:3])
Expected Output
Step Slicing (every 2nd): [10 30 50]
Reversed Array: [50 40 30 20 10]
2D Sliced Submatrix:
[[20 30]
[50 60]]
9 Reshape
Definition: reshape() changes the shape (dimensions) of an array without modifying its data.
Constraint: The total number of elements must remain identical before and after reshaping!
PYTHON • RESHAPE 
import numpy as np

arr = np.array([1, 2, 3, 4, 5, 6])
new_arr = arr.reshape(2, 3)

print("Original 1D:", arr)
print("Reshaped 2D (2x3):")
print(new_arr)
Expected Output
Original 1D: [1 2 3 4 5 6]
Reshaped 2D (2x3):
[[1 2 3]
[4 5 6]]
10 Flatten
Definition: flatten() converts a multi-dimensional array into a 1-dimensional array.
flatten() always returns a copy (occupies new memory).
PYTHON • FLATTEN 
import numpy as np

arr = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

flat_arr = arr.flatten()
print("Flattened 1D Array:", flat_arr)
Expected Output
Flattened 1D Array: [1 2 3 4 5 6]
11 Ravel (ravel vs flatten)
Definition: ravel() converts a multi-dimensional array into a 1D array.
Key Difference: flatten() returns a copy (separate memory), whereas ravel() returns a view (shares same memory) whenever possible!
PYTHON • RAVEL DEMO 
import numpy as np

arr = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

ravel_arr = arr.ravel()
print("Ravel 1D Array:", ravel_arr)
Expected Output
Ravel 1D Array: [1 2 3 4 5 6]

14 Axis Concept (Axis=0 vs Axis=1)
Definition: axis specifies the direction of operations in multi-dimensional arrays.
For a 2D Array:
• axis=0: Operation across rows (Downwards / Column-wise sum)
• axis=1: Operation across columns (Horizontal / Row-wise sum)

axis=0 (Column-Wise)

↓ Moves Down Rows

Sum of col 0, col 1, col 2

axis=1 (Row-Wise)

→ Moves Across Columns

Sum of row 0, row 1

PYTHON • AXIS DEMO 
import numpy as np

arr = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

print("Sum axis=0 (Column-wise):", np.sum(arr, axis=0))
print("Sum axis=1 (Row-wise):", np.sum(arr, axis=1))
Expected Output
Sum axis=0 (Column-wise): [50 70 90]
Sum axis=1 (Row-wise): [60 150]

16 Boolean Indexing / Filtering
Definition: Extracting array elements that satisfy specific conditional logic using bitwise operators & (AND), | (OR).
PYTHON • BOOLEAN FILTERING 
import numpy as np

arr = np.array([10, 20, 30, 40, 50])

/* Single Condition */
result = arr[arr > 25]
print("Elements > 25:", result)

/* Multiple Conditions (&) */
result_multi = arr[(arr > 20) & (arr < 50)]
print("20 < Elements < 50:", result_multi)
Expected Output
Elements > 25: [30 40 50]
20 < Elements < 50: [30 40]

18 Combining Arrays (Concatenate, vstack, hstack)
Definition: Joining multiple arrays together.
• concatenate(): Joins arrays along specified axis.
• vstack(): Stacks arrays vertically (row-wise).
• hstack(): Stacks arrays horizontally (column-wise).
PYTHON • STACKING & CONCATENATION 
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print("Concatenate:", np.concatenate((a, b)))
print("Vertical Stack (vstack):")
print(np.vstack((a, b)))
print("Horizontal Stack (hstack):", np.hstack((a, b)))
Expected Output
Concatenate: [1 2 3 4 5 6]
Vertical Stack (vstack):
[[1 2 3]
[4 5 6]]
Horizontal Stack (hstack): [1 2 3 4 5 6]

22 Copy (Deep Copy)
Definition: copy() creates a separate, independent duplicate array in memory. Modifying the copy does NOT affect the original array.
PYTHON • COPY 
import numpy as np

arr = np.array([10, 20, 30])
new_arr = arr.copy()
new_arr[0] = 100

print("Original:", arr)
print("Copy:", new_arr)
Expected Output
Original: [10 20 30]
Copy: [100 20 30]
23 View (Shallow View)
Definition: view() creates a new array object pointing to the SAME underlying memory buffer. Modifying the view WILL alter the original array!
PYTHON • VIEW 
import numpy as np

arr = np.array([10, 20, 30])
new_arr = arr.view()
new_arr[0] = 100

print("Original (Modified!):", arr)
print("View:", new_arr)
Expected Output
Original (Modified!): [100 20 30]
View: [100 20 30]

25 NumPy + Pandas Integration
Definition: Convert Pandas DataFrames/Series into native NumPy arrays using to_numpy() for high-performance numerical operations.
PYTHON • PANDAS TO NUMPY 
import numpy as np
import pandas as pd

df = pd.DataFrame({
    "Name": ["A", "B", "C"],
    "Age": [20, 25, 30]
})

/* Series to NumPy */
age_array = df["Age"].to_numpy()

/* Full DataFrame to NumPy */
data_array = df.to_numpy()

print("Age NumPy Array:", age_array)
print("DataFrame to Array:")
print(data_array)
Expected Output
Age NumPy Array: [20 25 30]
DataFrame to Array:
[['A' 20]
['B' 25]
['C' 30]]
