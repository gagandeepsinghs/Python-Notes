Chapter 2

Naming Rules & Conditions

Python variables standard syntax rules follow karte hain. In rules ko disregard karne par syntax errors arise hote hain:

  1. Cannot start with a number: Variable names number se start nahi ho sakte (e.g. 1x invalid syntax par x1 valid hai).
  2. No special characters except underscore (_): Variable names me special characters (like !, @, $, -, or spaces) allowed nahi hote. Faqat underscore (_) allowed hai (e.g. first_name valid, last name invalid).
  3. Case-Sensitive: Python case-sensitive language hai. name aur Name do completely different variables treat hote hain.

Chapter 3

Data Types in Python

Variables multiple types of values store kar sakte hain. Python auto-detects variable data types based on the value assigned:

  • String (str): Sequence of characters enclosed in single quotes (' ') or double quotes (" ").
  • Integer (int): Whole numbers without decimal points.
  • Float (float): Decimal numbers.
  • Boolean (bool): Stores only two truth values: True or False.

Chapter 5

F-Strings Formatting

An f-string (formatted string literal) is used to insert variables or expressions inside a string using curly braces {}.

Syntax: f"sentence {variable}"

Expression evaluation inside f-strings

F-strings accept valid Python math operations inside curly braces directly: f"Cost = {price * quantity}".
